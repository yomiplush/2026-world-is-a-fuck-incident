May 8, 2024 ACL syntax updates As part of a security fix to address an issue related to exit nodes and subnet routing ( TS-2024-005 ), changes are made to ACLs . The meaning of * when used in the src field in ACLs has been changed. Previously, * expanded to include any IPv4 and IPv6 address. With this change, * expands to all Tailscale IP addresses and all IP addresses from approved subnet routes . The new autogroup:danger-all ACL type has been added, which matches the previous definition of * when used in the src field. If you are using default ACLs or have specified * in src , you don't need to make any ACL changes to get the new secure behavior.
