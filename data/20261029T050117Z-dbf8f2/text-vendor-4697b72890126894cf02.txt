MNDT-2026-0039
Description
A critical and a high-severity vulnerability exist in the Aquila on-premises deployment, in versions up to 2.6.7.2. The vulnerabilities lead to container root-level remote code execution, authentication bypasses, and sensitive information disclosure. Mandiant observed that an improperly restricted API endpoint allows persistent injection of dynamic Lua scripts that are subsequently evaluated by backend execution engines.
Impact
Critical - A remote authenticated or low-privileged attacker can exploit these vulnerabilities to achieve arbitrary code execution as container root, bypass zero-trust tunnel authorization controls to access internal network assets, and harvest sensitive deployment keys. This can lead to a full system and enterprise perimeter compromise.
Exploitability
High - Exploitation does not require advanced techniques or victim interaction. Attackers can leverage exposed API endpoints directly from the public internet and through edge proxies with leaked credentials to achieve code execution with authentication code obtained from other avenues.
CVE ID
CVE-2026-104383 - Remote Code Execution via Stored Lua Injection
Common Weakness Enumeration
CWE-94: Improper Control of Generation of Code ('Code Injection')
Details
An injection flaw in the Pigeon MFA service allows callers to persist and trigger arbitrary Lua scripts via execution runtimes lacking proper sandboxing, running under container root privileges.
CVSS
CVE-2026-104383 - CVSS:4.0/AV:N/AC:L/AT:N/PR:L/UI:N/VC:H/VI:H/VA:H/SC:H/SI:H/SA:H (9.4)
Resolution
The issue was fixed in the following Aquila on-premises version: 2.6.7.3
Discovery Credits
Liu Yong, TS Lab
Sun Pu, Mandiant
