Corporate 2026. 10. 09

オンラインコミュニティー「Sansan User Forum」における会員情報漏えいに関するお詫びとお知らせ

このたび、当社が運営するユーザー向けオンラインコミュニティー「Sansan User Forum」が利用している外部クラウドサービス「Commune」において、第三者による不正アクセスが発生し、本コミュニティーに登録されている会員の個人情報の一部が漏えいしたことが判明しました。対象の皆さまには、本日10月9日、個別のご案内を実施済みです。

本コミュニティーの会員の皆さまには多大なご心配とご迷惑をおかけしますことを、深くお詫び申し上げます。

▪️経緯
2026年10月6日、「Sansan User Forum」で利用するクラウドサービス「Commune」の提供事業者「コミューン株式会社」（以下、コミューン社）から、第三者による不正アクセスを受けたとの報告がありました。同社の調査により、本コミュニティーの会員情報の一部が取得・閲覧された可能性があると報告を受けています。本コミュニティーは現在、一時的にサービスを停止しており、当社とコミューン社が連携して、原因と影響範囲の調査を進めています。

本件はコミューン社のシステムに対する攻撃により発⽣したものです。本コミュニティーは当社の各サービスとは独立した外部クラウドサービス上で運営されており、営業AXサービス「Sansan」、経理AXサービス「Bill One」、契約AXサービス「Contract One」、名刺アプリ「Eight」などのシステムおよび各サービスでお預かりしている情報への影響はありません。

※コミューン社によるリリースは、こちらからご確認いただけます。
https://communeinc.com/ja/news/2026oct09

▪️漏えいした可能性のある情報
オンラインコミュニティー「Sansan User Forum」の一部の会員情報

・漏えいが確認された対象人数：1325名
・対象情報：メールアドレス、アカウント名（表示名）、自己紹介欄の記載内容、プロフィール画像、本コミュニティー内のグループ所属情報

・漏えいの可能性がある対象人数：8687名
・対象情報：アカウント名（表示名）、自己紹介欄の記載内容、プロフィール画像、本コミュニティー内のグループ所属情報

※コミューン社調査による報告をもとにした2026年10月9日時点の情報です。
※パスワードは含まれていません。

■対応状況
当社およびコミューン社では、以下の対応を行っております。

・10月6日　コミューン社による「Sansan User Forum」のサービス停止
・10月7日　当社が、コミューン社から調査結果の報告（速報）を受領
・10月9日　当社が個人情報保護委員会に対して報告
「Sansan User Forum」の全会員に不正アクセスが発生した旨をメールで通知

▪️「Sansan User Forum」会員の皆さまへのご案内について
漏えいが確認された、および漏えいの可能性がある会員の皆さまには、ご登録のメールアドレスへ個別にご案内を実施済みですので、ご確認をいただきますようお願いします。

▪️今後の対応について
安心してユーザーコミュニティーをご利用いただけるよう、コミューン社における再発防止に加え、当社による管理監督を徹底してまいります。

今後、本コミュニティーの再開についてや、新たな事実が判明した場合は、ウェブサイトへの掲載および対象の皆さまへ個別にご連絡いたします。

本件についてご不明な点は、下記の問い合わせ窓口までご連絡ください。

Sansan Innovation Community運営事務局
Mail：community@sansan.com
