## HTTP2Shell / Brotli：名前はHTTP/2、欠陥はdecoder

二次記事 [HTTP2Shell Vulnerability](https://cybersecuritynews.com/http2shell-vulnerability/) は取得時HTTP 403でした。技術条件は一次資料へ戻します。Node2Shell / HTTP2Shell / Brotli2Shellはいずれも **CVE-2026-111497** の通称です。HTTP/2のフレーム処理そのものの欠陥ではありません。攻撃者が制御するBrotliバイト列が脆弱なC decoderへ到達した場合の範囲外書き込みです。

上流の影響範囲は **1.0.3以上1.0.10未満 / 1.1.0以上1.1.1未満 / 1.2.0以上1.2.1未満**。修正タグは **1.0.10 / 1.1.1 / 1.2.1**。Google CNAは CVSS v4.0 **9.2**。Node.jsの修正は **22.23.4 / 24.22.1 / 26.12.1**。`Accept-Encoding` から `br` を外すだけでは、相手が送るbr応答やファイル経路を防げません。詳細と下流の到達は[Brotli追補](26-brotli-http2shell.ja.md)と[固定窓調査](research-collection-2026-10-27-0018.md)へ。

[JFrog Brotli2Shell（10/25）](https://research.jfrog.com/post/brotli2shell-beyond-node2shell-and-http2shell/)は、HTTP以外の到達を一次分析しています。.NETはネイティブdecoderのSIGSEGV（RCE実証なし）、修正ランタイム **8.0.33 / 9.0.22 / 10.0.14 / 11 rc.3.26522.148**。ASP.NET Core / HttpClient のBrotli自動展開は既定オフ。NativeAOTは共有runtime更新だけではdecoderが置換されず、再発行が必要です。[dotnet/announcements#494](https://github.com/dotnet/announcements/issues/494)

FFmpeg経由のlibjxl `brob` 箱では、JFrogが命令ポインタ相当の破壊（`0x414141414141`）を観測。libjxl mainは1.2.1へbump済みですが、取得時点で**修正済みのlibjxl/FFmpegリリースは確認していません**。ClickHouseは `Content-Encoding: br` の約23 MB入力で遠隔crash、PR [#127419](https://github.com/ClickHouse/ClickHouse/pull/127419) はmerge済み、JFrog公表時点では**修正リリース未出荷**。Apache Arrow / pyarrow は534バイト入力で無限ループ、issue [#55166](https://github.com/apache/arrow/issues/55166) は取得時点でopen。いずれもNode.js公式イメージでのImperva RCE実証と同一視しません。

Cloudflareの10/25緊急WAFは受信 `Content-Encoding: br` と `/_next/image` の2ルール、**既定はLog**です。Logを遮断完了とせず、ruleset全体のBlock上書きの有無を先に確認します。
