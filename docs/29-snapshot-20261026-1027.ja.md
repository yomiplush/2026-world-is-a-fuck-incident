### NNabla：モデル変換とparameterを信頼しない

CVE収録・公式コード照合 / 10:17:15 JSTに2件収録、原報告は以前。

CVE-2026-116103 / -116104はencode_paramとNNP converterの入力評価経路。CNAは1.39.0まで、非サポート製品と記載。全推論APIで無条件にネットワークRCEが成立するとはしない。

**対応：** 最低修正版は未確定。不審なparameterやNNPを変換せず、処理環境・資格情報・外向き通信を隔離する。

[公式encode/decodeコード](https://github.com/sony/nnabla/blob/master/python/src/nnabla/utils/cli/encode_decode_param.py) / [公式converterコード](https://github.com/sony/nnabla/blob/master/python/src/nnabla/utils/converter/utils.py) / [CNA記録](https://nvd.nist.gov/vuln/detail/CVE-2026-116103)

[smg公式1.11.0](https://github.com/smg-project/smg/releases/tag/v1.11.0) / [llama.cpp公式修正PR](https://github.com/ggml-org/llama.cpp/pull/30902) / [研究者の再現と未完PR](https://github.com/ggml-org/llama.cpp/pull/29360)
