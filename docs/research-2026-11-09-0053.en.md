## OpenAM: notification WebSocket session-token exposure and SAML / self-registration authentication boundaries

In CVE-2026-123551 (from 14.0.0 before 16.1.4), an internal forward on legacy Liberty ID-FF endpoints reaches the notification WebSocket without authentication and exposes live iPlanetDirectoryPro tokens. In CVE-2026-123550 (before 16.1.4), ECP (PAOS) and HTTP-Artifact bindings accept unsigned assertions when WantAssertionsSigned is disabled. In CVE-2026-123549 (before 16.1.4), self-registration fails to enforce Valid Creation Attributes and permits joining administrative groups. The GitHub advisories were published on 10/22, distinct from this NVD registration date.

Update to 16.1.4 and inspect exposure of the notification WebSocket and Liberty ID-FF endpoints, SAML SP WantAssertionsSigned settings, and whether self-registration is enabled. Separate patch deployment from revoking and auditing existing sessions and unauthorized accounts.

## OpenEMR: 8.3.0 / 8.4.0 release-line fixes across SQL injection, file operations and OneTimeAuth

CVE-2026-124469 (Fee Sheet ORDER BY SQL injection) and CVE-2026-124450 (arbitrary file read/write via disposeDocument in the fax/sms module) affect versions before 8.3.0 and are fixed in 8.3.0. By contrast, CVE-2026-124445 (OneTimeAuth token replay and PIN brute force from 7.0.1 before 8.4.0) and CVE-2026-124467 (chained RCE via ESign router LFI and fax upload before 8.4.0) are fixed in 8.4.0. Verify a release at 8.4.0 or later and do not conflate 8.3.0 fixes with 8.4.0 fixes. Check whether the fax/sms and ESign modules are enabled, and investigate suspicious access to sqlconf.php, temporary upload paths and patient-portal token usage.

## Kyverno: cross-namespace boundary bypass via apiCall and variable generate targets

In CVE-2026-124440 (from 1.19.1 before 1.19.2), malformed percent-encoding bypasses the apiCall namespace clamp and allows calling cross-namespace or cluster-scoped APIs with the admission-controller ServiceAccount privileges. In CVE-2026-124441 (before 1.19.2), templating the generate rule's kind and namespace with variables skips authorization checks and allows creating resources in arbitrary namespaces via the background-controller. Both require permissions to create a Policy within a namespace.

Update to 1.19.2 and audit delegated namespaced Policy creation permissions, Policies using apiCall or variable generate rules, and creation history for unexpected MutatingWebhooks or RoleBindings.

## Craft CMS: out-of-scope GraphQL reads and control-panel signing oracle

In CVE-2026-124427 (from 5.0.0 before 5.11.2), public GraphQL schemas or scoped tokens can traverse prev/next fields to read entries from out-of-scope sections. In CVE-2026-124430 (from 5.10.0 before 5.11.2), non-administrator control-panel users can obtain HMAC-signed Twig templates from app/render-elements and achieve code execution via the login redirect. Keep unauthenticated GraphQL prerequisites distinct from control-panel privilege prerequisites.

Update to 5.11.2. Review public GraphQL schema availability and token scopes, non-administrator control-panel permissions, and request logs for app/render-elements.

## imgproxy: ICO loader integer overflow and staged fixes across 4.0.16 / 4.0.17

CVE-2026-123614 affects 4.0.0 before 4.0.16, where an ICO data_size integer overflow causes heap corruption and RCE, fixed in 4.0.16. Meanwhile, CVE-2026-123615 affects 3.3.0 before 4.0.17, where BMP header reconstruction on a small ICO data buffer causes out-of-bounds heap read/write, fixed in 4.0.17. Because CVE-2026-123615 remains present in 4.0.16, do not conflate affected and fixed releases.

Update to 4.0.17 or later. Do not treat 4.0.16 as a complete fix for both CVEs; inspect routes that accept external image URLs and check worker crash history.

## Hickory DNS: DNSSEC validation bypass and unpatched legacy hickory-proto range

CVE-2026-123587 affects hickory-net from 0.26.0 before 0.26.2, permitting wraparound NSEC nonexistence forgery via comparison against an unvalidated SOA record. CVE-2026-123605 fails to verify that the RRSIG Signer's Name matches the target RRset's zone, permitting signatures from another zone's key; while hickory-net is fixed in 0.26.2, legacy hickory-proto 0.1 through 0.25.0-alpha.3 lists Patched versions as None (unprovided) in the GitHub advisory.

Update hickory-net to 0.26.2 or later. Note explicitly that legacy hickory-proto 0.1 through 0.25.0-alpha.3 has no in-series fixed release and requires migrating to hickory-net 0.26.2 or later; review dependency trees that rely on DNSSEC validation.
