## IBM Concert and DataStage: OS command execution and path traversal

In IBM Concert 1.0 through 3.0.1.1, CVE-2026-6715 and CVE-2026-15266 (both CVSS 9.8) allow OS command execution via crafted input or unsafe command-execution components. In DataStage on Cloud Pak for Data 5.4.0.0, CVE-2026-107331 (CVSS 9.9, absolute path traversal), CVE-2026-107330 (SSRF), and CVE-2026-16427, CVE-2026-16433 and CVE-2026-81542 (arbitrary file write/delete) were registered. Initial IBM bulletin publication occurred on 10/29 and 10/27, distinct from this NVD registration date.

Update IBM Concert to 3.1.0 and DataStage on Cloud Pak for Data 5.4.0.0 to 5.4 patch 8 or later. Distinguish unauthenticated Concert reachability from authenticated DataStage prerequisites, and audit host command-execution and file-modification history.

## IBM Process Mining: 2.2.1 vs. 2.2.1 IF001 boundary and On-Prem case delivery

IBM Process Mining 2.0.0 through 2.2.1 is affected by CVE-2026-114464 (CVSS 9.3, sensitive information disclosure via improper access control), CVE-2026-108292 (dangerous file upload), CVE-2026-112369 (client-side security enforcement) and CVE-2026-93005 (email notification rate-limiting DoS). Version 2.2.1 is an affected release, whereas the fix is in 2.2.1 IF001. For On-Prem deployments, the bulletin instructs opening an IBM Support case to receive 2.2.1 IF001 delivery.

Do not treat 2.2.1 as fixed; verify that 2.2.1 IF001 is applied. Distinguish OCP upgrades from On-Prem delivery via IBM Support cases, and inspect logs for unauthorized file uploads or information access.

## Qiskit SDK: QPY deserialization, C API out-of-bounds write and v2.6.2 table discrepancy

CVE-2026-116501 (out-of-bounds write in qk_circuit_inst_unitary) and CVE-2026-116500 (unbound recursion DoS in QPY format v13 or later) affect v2.4.0 through v2.6.1 and are fixed in v2.6.2. By contrast, for CVE-2026-116499 (arbitrary Python code execution via qiskit.qpy.load on QPY format versions before 13), both the IBM bulletin and NVD list Affected versions as v1.4.2 through v2.6.2 while also naming v2.6.2 as the patched release, creating an internal contradiction for v2.6.2.

Verify v2.6.2+ installation alongside the actual SymPy-removal patch state, and do not pass untrusted QPY binaries directly to qiskit.qpy.load() or C API functions. Preserve the bulletin's v2.6.2 version discrepancy without rounding.

## IBM Bob Shell and Langflow OSS: automatic MCP execution and local isolation bypass

IBM Bob Shell 1.0.4 through 2.0.1 (CVE-2026-9764) automatically executes workspace-defined MCP server configurations without user consent when opening an untrusted repository, fixed in 2.0.2 via Workspace Folder Trust. The IBM bulletin explicitly notes that the precaution of opening only trusted repositories is partial ("do not fully address the vulnerability"). Langflow OSS 1.0.0 through 1.12.2 (CVE-2026-97677) allows authenticated flow authors to bypass local file isolation and read/write configuration, secret or database files, fixed in 1.12.3.

Update IBM Bob Shell to 2.0.2 or later and Langflow OSS to 1.12.3 or later. Do not treat operational precautions as a complete fix; inspect previously opened repositories for MCP configurations and check Langflow data directories and secrets for exposure.

Melapress Role Editor 1.3.0 and earlier has CVE-2026-109900 (CVSS 9.6, unauthenticated-initiated privilege escalation requiring user interaction) and CVE-2026-109899 (Subscriber broken access control), fixed in 1.4.0. AnyWhere Elementor 1.3.0 and earlier has CVE-2026-114189 (Subscriber Blind SQL injection, noted by Patchstack as colliding with CVE-2026-103914 from another CNA), CVE-2026-114186 and CVE-2026-114188, fixed in 1.3.1.
