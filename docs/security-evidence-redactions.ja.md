# 証拠資料のキー伏せ処理

2026年10月30日、保存HTML（gzipを含む）4ファイル内の外部サイト由来のGoogle APIキーを `[REDACTED_GOOGLE_API_KEY]` に置換しました。指摘されたImpervaの資料では、取得元サイトの `GOOGLE_GEOCODE_CLIENT_API_KEY` 設定が保存されていました。これだけでInfosec Briefingの侵害や、キーの所有者・有効性・制限設定が確認されたわけではありません。キーの使用・有効性テストは実施していません。

[処理記録](../data/evidence-redactions.json)に、対象パス、処理前後の保存バイト列のSHA-256、更新した整合性マニフェストを記載しました。更新後のハッシュは**キーを伏せた資料**のもので、取得時の原本そのものではありません。取得時のヘッダーは過去のメタデータとして残しています。記事内容と調査記録は保持し、gzipは決定的に再圧縮しました。原本保存方針に対する例外として処理を記録しています。

証拠資料の公開前に `python3 tools/intel/check-saved-secrets.py` を実行してください。追跡ファイルとgzip展開後の本文にあるGoogle APIキー形式を検査し、キー値は出力しません。全種類の秘密情報を検出するものではなく、Git履歴は検査しません。

現在のコピーを削除してもキーは失効せず、過去のGitコミット・既存のクローン・フォーク・GitHubのキャッシュからも消えません。所有者側で制限設定を確認し、必要に応じてキーを無効化・再発行する必要があります。Git履歴の削除、調整を伴う強制Push、GitHubの秘密情報アラートの解決は別の作業です。初回の処理では履歴の書き換えやキーの無効化は実施していません。その後の履歴処理は以下に記録します。キーの無効化は引き続き未確認です。

## 2026年10月30日の履歴書き換え

運営者の明示的な依頼に基づき、隔離したミラーに `git-filter-repo` 2.47.0 を使用し、取得できた全履歴の通常・gzipバイト列からGoogle APIキー形式を伏せました。105コミットを処理し、処理前は過去の4つのblobで検出、処理後は到達可能な過去のblob 4,028個を検査して検出0件でした。この履歴処理で現在のmainのファイル内容は変わっていません。ブランチ名を保持し、取得時のSHAを条件とした原子的な強制Pushで公開するため、処理中の他者の更新は上書きしません。

公開ブランチは8本、公開タグはありません。影響を受けるPR参照は12個です。GitHubの読み取り専用PR参照や元コミットのキャッシュは、ブランチの強制Pushでは削除できず、GitHub Supportでの別途対応が必要になる場合があります。問い合わせは送信していません。問い合わせ用の記録として、最初に変わった元コミットは `a48cebdc2586fd76b701ac96d85cab0b358fd466` です。フォークや他者のクローンは今回の削除範囲外です。既存の作業コピーは再クローンし、古い履歴をマージし直さないでください。

全履歴のマニフェストを遡って再計算したわけではなく、古いコミットのハッシュ記録は伏せ字処理前の資料に対応する場合があります。現在のmainには、初回処理で作成した明示的な処理記録と修正したマニフェストがあります。コミットSHAに固定したリンクは手動更新が必要な場合があります。この作業は、キーの失効・GitHubの全キャッシュ削除・秘密情報アラートの解決を確認するものではありません。
