## Editorial priorities

- **Gitea 28.4.0 (20 CVE fixes):** The official Gitea 28.4.0 release disclosed 20 CVEs (18 included in this NVD publication window, 1 RubyGems newline injection previously fixed in `28.3.0` [`CVE-2026-118389`], and 1 Go `1.27.4` runtime update). Most notably, repository creation with auto-init accepted pushes before initialization finished, allowing a symlink README write to overwrite server-side git hooks and execute arbitrary commands as the Gitea system user (`CVE-2026-125423`), while dashboard search (`GET /repo/search`) in `28.0.0` and later returned repository owners' password hashes, salts, and email addresses inside commit status objects (`CVE-2026-123006`). Additional fixes cover git-quoted protected file pattern bypass (`CVE-2026-123638`), persistent scoped workflow registrations after repository transfer (`CVE-2026-118535`), unlimited TOTP attempts (`CVE-2026-123002`), and disabled-user OAuth2/OIDC refresh token reuse (`CVE-2026-128359`). Upgrade to **`28.4.0` or later**, consider resetting owner passwords if commit statuses were exposed on `28.0.0`–`28.3.x`, and audit transferred repositories' scoped workflows.
- **Cyrus SASL SRP authentication bypass (`CVE-2026-129483`) and OkHttp certificate pin bypass (`CVE-2026-129482`):** In Cyrus SASL `<= 2.1.28`, `srp_server_mech_step2` (`plugins/srp.c`) fails to verify whether the client public value `A` satisfies `A % N == 0`; sending `A = N` forces the shared secret to zero and allows an unauthenticated client to authenticate as any existing user (CVSS 4.0 9.3). With no new upstream release since 2022, upstream removed the SRP plugin in commit `fb3724f4`. In OkHttp `<= 5.5.1`, `CertificatePinner` (`Pin.matchesHostname`) does not normalize trailing-dot FQDNs (e.g., `example.com.`), skipping pin checks when connecting with a trailing dot (fixed in commit `30aa5897`; no fixed release version listed in NVD at capture time).
- **vLLM, dufs, and Kroki:** Disclosed issues include a race condition in `single_type_kv_cache_manager.py` (Common Prefix Handler) in vLLM `0.30.0` and `0.31.0` (`CVE-2026-129356`, fixed in `0.32.0` and commit `e687a251`), an authorization flaw in the WebDAV `COPY` handler (`src/server.rs`) of dufs `<= 0.46.0` allowing file overwrite without delete permission (`CVE-2026-129355`, fixed in `0.47.0` and commit `fba13dff`), and two additional Kroki `< 0.36.0` advisories fixed in `0.36.0`: BlockDiag node `icon`/`background` SSRF and local image read (`CVE-2026-129485`, `GHSA-jwh8-j584-79hp`) and reflected XSS on `GET /goat/svg` (`CVE-2026-129484`, `GHSA-xp94-px2v-f7f2`).
- **Assimp, GPAC, littlefs, MicroQuickJS, and Escargot:** Assimp `<= 6.0.6` has four disclosures with upstream PRs (`#7026`–`#7029`) and no fixed release version listed in NVD (`CVE-2026-129477` glTF `buffers[].uri` path traversal, `CVE-2026-129478` `ParseDataURI` `signed char` offset heap OOB read over 127 bytes, `CVE-2026-129479` `OgreBinarySerializer::ReadSubMesh` 32-bit integer overflow, `CVE-2026-129480` `MD2Importer::InternReadFile` heap OOB read). GPAC `< 26.02.0` fixes four MPEG-2 TS, XMT, and DASH flaws (`CVE-2025-71466`–`CVE-2025-71469`) in `26.02.0` (commit `62714f27`); littlefs `<= 2.11.3` `LFS_MIGRATE` type confusion (`CVE-2026-129490`, no fixed version listed), MicroQuickJS `JS_Call()` stale frame pointer traversal (`CVE-2025-71470`, commit `99eed3f9`), and Samsung Escargot `5.0.2` use-after-free (`CVE-2026-124684`, commit `8bc35b7b`) keep their exact patch states explicit.
- **PrestaShop, FRRouting, and FreedomBox revisions:** Modified-window refinements cover PrestaShop `< 8.2.9` / `< 9.2.1` multi-shop Webservice API boundary bypasses (`CVE-2026-71519`, `CVE-2026-71531`, fixed in `8.2.9` and `9.2.1`), FRRouting `bgpd` Tunnel Encapsulation use-after-free (`CVE-2026-129456`) narrowed to peers with `soft-reconfiguration inbound` where `attr_intern_reuse` compares the attribute against itself (commit `5c241056`), and FreedomBox `< 26.15` `authorized_keys` path validation (`CVE-2026-123962`, fixed in `26.15`).
- **Enterprise/cloud management, routers, WordPress plugins, and 5 malicious package advisories:** We cataloged Zr.Admin.NET (5 CVEs, no fixed version), GeoPulse `1.5.0`–`2.3.0` (`CVE-2026-129467`, commit `b994ec58`), Netcccyun `dnsmgr` `< 2.22` (`CVE-2026-129468`, fixed in `2.22`), `Course-tencent-cloud` `< 2.0.2` (`CVE-2026-129469`, fixed in `2.0.2`), Linux Foundation Magma `<= 1.9.0` (4 CVEs, vendor unresponsive / no fix), DrayTek Vigor2960 `<= 1.5.1.6` (5 CVEs, update to `1.5.1.7` noted alongside a planned follow-up release), legacy/EoL D-Link routers, 56 WordPress plugin CVEs (including Custom Block Builder `< 3.0.0` unauthenticated RCE `CVE-2026-127048`), and affected version tables for 5 GHSA malware advisories (3 npm, 2 pip).
