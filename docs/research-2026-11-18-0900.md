## 主な論点と編集方針

- **libp2p（gossipsubトピックマップ肥大化とASN.1 DERデコーダ停止）:** P2Pネットワーキングスタックjs-libp2pにおける2件の深刻なDoS脆弱性修正（`CVE-2026-119793` / `GHSA-x2vm-cf3p-m2w8`、`CVE-2026-110789` / `GHSA-rvfr-cqwq-rc4j`）。購読RPCによるtopicsマップ無制限肥大化をgossipsub `17.0.0` で、Identify公開鍵ASN.1 DERデコード時の4〜5秒イベントループ停止をcrypto `5.1.22` で修正。
- **SimpleSAMLphp SAML2（HTTP-Artifact署名検証迂回）:** SAML2ライブラリにおけるCVE-2026-49283の不完全修正（`CVE-2026-110782` / `GHSA-r7hw-jx6r-756g`）。`HTTPArtifact::receive()` において埋め込みResponseのIssuerとArtifact解決元エンティティの拘束が欠落していた問題を `6.2.4` および `7.0.0-rc2` で修正。
- **EGroupware（SAML IdP選択パラメータ誘導）:** グループウェアEGroupwareにおける外部IdP指定の不備（`CVE-2026-63672` / `GHSA-pr4x-6fj4-gm4h`）。`$_REQUEST['idp']` が未検証でSimpleSAMLphpに渡され、攻撃者が悪意あるIdPへ誘導できる問題を `23.1.20260601` および `26.6.20260616` で修正。
- **Next.js 16.4.5（ネストされたuse cacheにおけるルート引数キャッシュ露出）:** Next.js `16.4.5`（`CVE-2026-119351` / `GHSA-vc7v-qv4w-wrv8`）。Cache Components有効時、ネストされた'use cache'関数間で内部ストリーム遅延によりキャッシュキーの不整合が発生し、異なるルートパラメータ間でデータが混同する問題を修正。
- **AWS Advanced JDBC Wrapper（キャッシュ汚染経由のJava直列化復元RCE）:** オープンソースドライバAWS Advanced JDBC Wrapper（`CVE-2026-14265` / `GHSA-c5q4-97jw-jggh`）。接続構成キャッシュにおける不安全なデシリアライズによりRCEに至る脆弱性をバージョン `4.0.1` で修正。
- **Arize Phoenix AI可観測性（applyChatTemplate書式文字列注入）:** AIモデル評価・追跡基盤Arize Phoenix（`CVE-2026-53998` / `GHSA-gfv3-m769-5xm3`）。`applyChatTemplate` GraphQLエンドポイントにおけるPython書式文字列注入による環境変数・暗号鍵の露出をバージョン `15.7.0` で修正。
- **Filament Curator（SVGインライン配信XSSとマルチテナント検索露出）:** Laravel Filamentメディア管理プラグイン（`CVE-2026-69241`、`CVE-2026-63389`）。非サニタイズSVGインライン配信による格納型XSSを `3.7.9` / `4.1.2` / `5.1.2` で、メディアピッカー検索クエリでのテナント制約欠落を `3.7.8` / `4.1.1` / `5.1.1` で修正。
- **qbee-agent 2026.27（createFileシンボリックリンク追従LPE）:** IoT・組み込みデバイス管理エージェントqbee-agent（`CVE-2026-62336` / `GHSA-xhv5-8fpq-g7hf`）。ファイルマネージャーのcreateFileヘルパーにおけるシンボリックリンク不適切処理によるローカル特権昇格を `2026.27` で修正。
- **CIRCUTOR SCADA WAVEとRucio（CVSS 10.0認証迂回）:** 産業用SCADA PowerStudio SCADA WAVEのJWT署名検証欠落による未認証管理者奪取（`CVE-2026-120387`）と、科学データ管理フレームワークRucioの `validate_auth_token` トークン検証迂回（`CVE-2026-100397`）の修正を整理。
- **npm悪意あるパッケージ126件:** GitHub Advisory Databaseのmalwareカテゴリに登録された126件（`GHSA-8x4p-wc99-jvgr`、`GHSA-cxwc-2pvw-6q7w`等）。`@nullzero/urlcat` や `json-asyncapi` など既存ライブラリを模倣し、インストールフックで環境変数や秘密鍵を窃取する不正パッケージの隔離と鍵失効手順を整理。
