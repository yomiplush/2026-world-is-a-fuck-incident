## Changes that affect decisions

- **Windows .NET — a previously announced fix was missing.** Microsoft issued an out-of-band correction for CVE-2026-70197. Reusing `SocketAsyncEventArgs` across IPv4/IPv6 datagram sockets can leave an undersized native address buffer. Check the matching runtime line: **8.0.33 / 9.0.22 / 10.0.14 / 11.0.0-rc.3.26522.148**. Rebuild and redistribute self-contained applications and verify the running runtime. The official issue was created **October 26, 03:50:05 JST**, verified against its API timestamp. This is patch delivery for an existing CVE, not a new attack date. [Microsoft advisory](https://github.com/dotnet/announcements/issues/493).
- **Siemens / industrial appliances.** JVN's October summary was updated at **09:00 JST**. SSA-566512 covers PHP2Shell in PAN-OS on RUGGEDCOM APE1808 configurations; it does not make every Siemens product affected. The underlying Siemens advisory was published October 23. Its monthly totals are advisory counts, not new attacks this morning. [JVN](https://jvn.jp/vu/JVNVU90141693/), [Siemens](https://cert-portal.siemens.com/productcert/html/ssa-566512.html).
- **PAN-OS patch availability changed.** The October 25 revision lists **10.2.18-h13 / 11.1.16-h4 / 11.2.10-h16** as released. Other lines retain separate ETAs. Match the model and release line, and restrict management access. [Vendor status](https://security.paloaltonetworks.com/CVE-2026-109618).
- **Perl HTTP processing.** The Starman and PSGI announcements were sent at 01:57 and 01:56 JST respectively; later feed timestamps are not their original sending times. Starman fixes four flaws in **0.4019**. The PSGI announcement has inconsistent version fields; its Solutions section recommends **Plack 1.0057 or later**. These are technical disclosures, not confirmed attacks. [Starman](https://seclists.org/oss-sec/2026/q4/388), [PSGI](https://seclists.org/oss-sec/2026/q4/387).
- **PHP attribution correction.** Unit 42 withdrew its October 23 statement linking a government incident's initial access to the specific PHP2Shell CVEs. The October 25 correction does not invalidate AWS's separate observations of exploitation attempts. Preserve the distinction between an attempt, compromise and attribution of initial access. [Correction](https://unit42.paloaltonetworks.com/cve-2026-109618-cve-2026-109619/).
