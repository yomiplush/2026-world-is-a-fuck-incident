## Key Topics and Editorial Policy

- **AIOHTTP 3.14.4 (9 Vulnerability Fixes):** AIOHTTP `3.14.4` release (`CVE-2026-129521` through `CVE-2026-129529`) addressing HTTP request smuggling via Transfer-Encoding header parsing anomalies, memory exhaustion DoS via compression bombs, and directory traversal in static file serving. Upgrades are recommended for installations running vulnerable versions `<= 3.14.3`.
- **Nuxt 4.6.4 (SSR State Pollution & Traversal Fixes):** Nuxt `4.6.4` (`CVE-2026-129530` through `CVE-2026-129534`) resolving state pollution via reactive property injection during SSR payload extraction, server-side file serving path traversal, and HTTP header injection. Users running `<= 4.6.3` should upgrade to `4.6.4`.
- **SvelteKit 3.1.1 (CSRF & Prototype Mutation Fixes):** SvelteKit `3.1.1` (`CVE-2026-129535` through `CVE-2026-129538`) mitigating form action CSRF bypass under specific reverse proxy rewrite configurations, object prototype mutation during data loader serialization, and reflected XSS in custom error pages.
- **Next.js 16.4.5 (Server Actions Cache Leak):** Next.js `16.4.5` (`CVE-2026-119790`) fixing an issue where Server Actions response caches could leak across tenants under ISR with dynamic route segments. Affected versions `16.4.0` through `16.4.4` should update to `16.4.5`.
- **MCP & AI Tooling Security (Kubeshark 53.4.0 & code-review-mcp-server 1.5.3):** Kubernetes traffic analyzer Kubeshark `53.4.0` (`CVE-2026-129541` through `CVE-2026-129543`, unauthenticated packet capture replay and WebSocket privilege escalation) and Model Context Protocol server code-review-mcp-server `1.5.3` (`CVE-2026-129544`, command injection via git diff argument parsing with crafted branch names).
- **Silverstripe Framework 6.2.13 (Post-Auth RCE & Auth Flaws):** Silverstripe `6.2.13` (`CVE-2026-129545` through `CVE-2026-129550`) resolving authenticated RCE via asset upload SVG sanitization bypass, timing attacks in member password reset token comparison, and SQL injection in GraphQL filters.
- **mail-parser 4.6.3 (Attachment Extraction Traversal):** mail-parser `4.6.3` (`CVE-2026-129551` through `CVE-2026-129556`) patching Zip Slip directory traversal during batch MIME attachment extraction, ReDoS in unfolded header line parsing, and stack exhaustion from recursive nested multipart envelopes.
- **NLTK 3.10.4 (Corpus Loader Code Execution):** NLTK `3.10.4` (`CVE-2026-129557` through `CVE-2026-129559`) fixing arbitrary code execution via unsafe pickle deserialization in pre-trained corpus loaders and directory traversal in corpus downloader zip archive extraction.
- **IoT & Sync Agents (qbee-agent 2026.41, Directus 12.3.1, termux-sync 1.2.4):** qbee-agent `2026.41` (`CVE-2026-129560`, file distribution Zip Slip), Directus `12.3.1` (`CVE-2026-129561`, import archive traversal), and termux-sync `1.2.4` (`CVE-2026-129562`, sync endpoint path traversal) hardening file boundary controls.
