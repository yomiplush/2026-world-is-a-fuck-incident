## Editorial priorities

- **UnrealIRCd (KEV addition, `CVE-2026-114713`):** On networks with two or more linked servers, newline injection in the IRCv3 `labeled-response` (`label`) tag allows an ordinary user to inject server-to-server commands with server or IRCOp authority. Upgrade to `6.2.7.1` or apply the zero-downtime `./unrealircd hot-patch bundle-20261107` and verify via `./unrealircd module-status|grep labeled-response`. Because the forum URL returned HTTP 403, the official maintainer advisory on Openwall `oss-security` is preserved.
- **Check Point Gaia OS (KEV addition, `CVE-2026-123039`):** `dynamic_server` creates `/tmp/dynamic_socket` with world-writable `0777` permissions, allowing local privilege escalation to root. Check Point `sk1000362` states that active exploitation was observed against a couple of dozen customers. Apply the Jumbo Hotfix Accumulator (R82.20 Take 14, R82.10 Take 52, R82 Take 132, or R81.20 Take 174+), verify socket permissions are `0660`, and audit `/var/log/dynamicCli.log`.
- **ScreenConnect / SCKit and RelayTrap:** Microsoft's November 13 analysis separates the reported server-side entry via RMM+ extensions (versions 1.0.31 and 1.0.32 accepting an empty access key when none was configured) from `RelayTrap`, the endpoint-to-technician spread path blocked by client `26.6.5+` (`CVE-2026-84869`). Operators must also hunt and remove rogue ScreenConnect clients, scheduled tasks and registry Run persistence.
- **Apache APISIX 3.20.0 (7 flaws):** Preserves plugin- and config-specific boundaries across `multi-auth`, `jwe-decrypt`, `forward-auth`, encoded dot-segment routing, `authz-keycloak`, `match_uri_encoded_slash` + `skip_mtls_uri_regex`, and `openapi-to-mcp`.
- **Dropbear SSH streamlocal forwarding:** The November 13 `oss-sec` disclosure (no CVE assigned yet) shows that `authorized_keys` `permitopen`/`permitlisten` restrictions are checked only on TCP forwarding (`svr-tcpfwd.c`) and ignored on default-enabled Unix domain socket forwarding (`svr-streamfwd.c`). No upstream patch is available yet; separate OS group memberships (such as `docker`) or disable streamlocal forwarding at compile time.
- **NLTK canonical vs. withdrawn duplicate advisories:** Seven of the 39 GHSA reviewed advisories carry `withdrawn_at` timestamps as duplicates of canonical NLTK 3.10.4 advisories. Both the five canonical records (`nltk-canonical-1114`) and the seven withdrawn duplicates (`nltk-withdrawn-duplicates-1114`) are preserved in the register so raw API tables remain complete without double-counting active vulnerabilities.
- **Unpatched / partially mitigated disclosures:** `@astrojs/node` (`CVE-2026-127908`), Tactical RMM (`CVE-2026-129165`) and Keep (`CVE-2026-129166`) list no fixed version in the retrieved primary records; no patched version is invented.
