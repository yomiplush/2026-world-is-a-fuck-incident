## IBM API Connect: authentication and hard-coded credentials

The records cover other-user access tokens and administrative control through hard-coded credentials. CVE-2026-16720 and CVE-2026-17403 affect 10.0.8.0–10.0.8.12 and 12.1.0.0–12.1.1.2. CVE-2026-17360 affects 12.1.0.0–12.1.1.2. IBM initially published on 11/5; 11/7 NVD registration is not attack onset.

Update the applicable line to 10.0.8.13 or 12.1.1.3. Review exposure, directory integration, unexpected token issuance and administrative actions. Separate deployment from assessment of existing credentials; these sources do not establish compromise of an individual environment.

## Keycloak: client-management roles reach JavaScript policies

Session state during client creation or import with authorization services enabled permits inline JavaScript policy upload restrictions to be bypassed. Authenticated delegated client-management privileges are required. Red Hat lists CVSS 9.1 and Important, marks packages Affected and supplies no fixed release. Its public_date is 2026-01-07, differing from this NVD registration date.

Review delegated manage-clients permissions, client imports and policy changes. Track product-specific Red Hat fixes without inventing a release. Default script restrictions alone do not establish protection against this path.

[Red Hat CVE JSON](https://access.redhat.com/hydra/rest/securitydata/cve/CVE-2026-120984.json)

## Fiber Admin: error-page configuration and a race condition

Before 4.0.1, an enabled custom database error page and a race with an administrator saving settings allow a request header to be written into a PHP file. Authentication is not required, but configuration and race prerequisites matter. WPScan lists 4.0.1 as fixed and 11/5 as initial publication.

Update to a release containing the 4.0.1 fix and inspect the custom database error-page setting and generated PHP files. Disabling a feature is distinct from completed patch deployment; correlate settings changes with access logs.

## LatePoint: reset-token values become SQL conditions

The NVD CNA description covers the booking plugin through 5.7.6: reset values can be treated as SQL conditions. Wordfence returned HTTP success with an empty body, so its text did not verify a fixed release.

Check official LatePoint releases and CNA remediation guidance and verify the deployed fix. Do not assert a minimum fixed release from the bodies verified here. Investigate resets, customer-account changes and booking-data access.
