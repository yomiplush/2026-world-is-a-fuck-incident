## Editorial priorities

- **Rucio:** SSH challenges are not authenticated credentials. Preserve four branch-specific fixes from the maintainer advisory. No assertion that all deployments were exploited.
- **Rails/ImageMagick:** attachment alone reaches image analysis under the stated mini_magick/policy/upload conditions. Disk service adds readable-secret exposure. Check the policy actually applies and mini_magick >= 5.1; an exposed secret must not remain a fallback.
- **Aspire:** the Dashboard requires its own update to 13.6.5. Neither 13.6.3/13.6.4 nor a .NET runtime update establishes a fixed running Dashboard. Check existing manifests, containers, AppHost-selected SDK, CLI bundle or custom path.
- **Hono:** separate core mount/wildcard behavior from the Node adapter and proxy interpretation of raw backslashes. Application middleware on the rewritten path is not automatically bypassed by the adapter issue.
- **pgEdge:** ordinary concurrent requests can mix shared BM25 indexes across tenants. The maintainer says the server's own logs cannot retrospectively identify affected responses. RAG Server product release 2.0.0 and Go module commit pseudo-versions are separate identifiers. Go LLM's fixed product release is 0.2.0; the advisory explicitly says no 0.1.2 product release exists.
- **ScreenConnect:** ConnectWise's November 12 18:45 UTC update distinguishes initial-access investigation, precautionary disabling in approximately 400 environments with relevant extensions, and the endpoint-to-technician spread technique blocked by client 26.6.5+. The approximately 400 environments are not confirmed compromises. Client updates, extension disabling and password resets do not remove persistence or necessarily revoke existing web/IdP sessions. Investigate using trusted out-of-band tooling.
- **Japan-facing notices:** retain Air Terminal 6's management-login prerequisite and official automatic-update statement, KUSANAGI's edition-specific Nginx scope and Apache exclusion, and the limited scope of JVN's Apache 2.4.71 notice.

Other reviewed dependencies retain exact upstream package ranges, first-patched fields and withdrawal timestamps. A missing fixed version is not replaced by an invented release. Dependency updates, deployment, restart, investigation and credential revocation remain separate actions.
