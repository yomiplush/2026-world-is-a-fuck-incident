## Key Topics and Editorial Policy

- **libp2p (gossipsub Topic Map Flooding & ASN.1 DER Decoder Stall):** Two severe DoS fixes in js-libp2p (`CVE-2026-119793` / `GHSA-x2vm-cf3p-m2w8` and `CVE-2026-110789` / `GHSA-rvfr-cqwq-rc4j`). Uncapped subscription RPCs flooding node topics maps fixed in `@libp2p/gossipsub` `17.0.0`; unbounded synchronous loop during Identify public key ASN.1 DER decoding stalling the Node.js event loop for 4–5 seconds fixed in `@libp2p/crypto` `5.1.22`.
- **SimpleSAMLphp SAML2 (HTTP-Artifact Signature Verification Bypass):** Incomplete fix for CVE-2026-49283 in the SAML2 library (`CVE-2026-110782` / `GHSA-r7hw-jx6r-756g`). `HTTPArtifact::receive()` failed to bind the embedded Response's Issuer to the artifact resolution entity, patched in `6.2.4` and `7.0.0-rc2`.
- **EGroupware (SAML IdP Selection Parameter Redirection):** Groupware platform EGroupware improper external IdP selection (`CVE-2026-63672` / `GHSA-pr4x-6fj4-gm4h`). `$_REQUEST['idp']` was passed without validation to SimpleSAMLphp, allowing attackers to direct users to rogue IdPs; fixed in `23.1.20260601` and `26.6.20260616`.
- **Next.js 16.4.5 (Nested use cache Root Parameter Cache Leak):** Next.js `16.4.5` (`CVE-2026-119351` / `GHSA-vc7v-qv4w-wrv8`) addressing cache key mismatch across nested `'use cache'` functions due to delayed inner stream metadata, leaking cached responses across root parameter values.
- **AWS Advanced JDBC Wrapper (Java Deserialization RCE via Cache Poisoning):** Driver wrapper (`CVE-2026-14265` / `GHSA-c5q4-97jw-jggh`) resolving unsafe Java object deserialization in connection configuration caching leading to RCE, patched in version `4.0.1`.
- **Arize Phoenix AI Observability (applyChatTemplate Format String Injection):** Arize Phoenix AI evaluation framework (`CVE-2026-53998` / `GHSA-gfv3-m769-5xm3`) fixing a Python format string injection vulnerability in the `applyChatTemplate` GraphQL endpoint that allowed reading server environment variables and secrets, patched in `15.7.0`.
- **Filament Curator (SVG Inline XSS & Multi-Tenant Search Leak):** Media manager plugin (`CVE-2026-69241`, `CVE-2026-63389`) fixing stored XSS via unsanitized inline SVG delivery in `3.7.9` / `4.1.2` / `5.1.2` and cross-tenant media metadata exposure in picker search in `3.7.8` / `4.1.1` / `5.1.1`.
- **qbee-agent 2026.27 (createFile Symlink Traversal LPE):** IoT and embedded device management agent (`CVE-2026-62336` / `GHSA-xhv5-8fpq-g7hf`) fixing local privilege escalation to root via symlink following in the createFile file-manager helper, resolved in `2026.27`.
- **CIRCUTOR SCADA WAVE & Rucio (CVSS 10.0 Authentication Bypasses):** CIRCUTOR PowerStudio SCADA WAVE missing JWT signature verification (`CVE-2026-120387`) allowing unauthenticated administrative takeover, and scientific data platform Rucio `validate_auth_token` verification bypass (`CVE-2026-100397`).
- **126 Malicious npm Packages:** 126 GHSA malware advisories (`GHSA-8x4p-wc99-jvgr`, `GHSA-cxwc-2pvw-6q7w`, etc.) imitating utility and mobile packages (`@nullzero/urlcat`, `json-asyncapi`) to exfiltrate developer tokens, cloud credentials, and SSH keys in `preinstall` / `postinstall` hooks.
