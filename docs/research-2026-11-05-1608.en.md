## Arc: DuckDB aliases and tenant boundaries

The advisory reports cross-database reads by authenticated tokens through DuckDB I/O aliases within the shared storage root. Its prose describes an unresolved issue including 26.06.2, while the structured API names a fix-equivalent commit version; these claims conflict.

Do not infer resolution from the API fix field alone. Verify file access boundaries per database and restrict access to the shared root.

## Payload: client uploads and collection permissions

Affected configurations enable client uploads in @payloadcms/storage-vercel-blob and let authenticated users access the upload route. Configurations without client uploads are outside this path.

Upgrade to 3.90.0 or 4.0.0-canary.34 or later. Until then disable client uploads or enforce collection permissions on the route.

[GHSA-mc8m-rr6c-r5qr](https://github.com/advisories/GHSA-mc8m-rr6c-r5qr)

## odf-kit: XSS through style attributes in converted documents

odtToHtml() and odsToHtml() interpolate unescaped style values. Inserting the output from a crafted document as HTML can execute script. Versions from 0.6.0 up to but excluding 0.14.2 are affected.

Upgrade to 0.14.2 or later and avoid directly displaying HTML from untrusted documents. Review previously converted output too.

[GHSA-3cgg-c5pp-57h6](https://github.com/advisories/GHSA-3cgg-c5pp-57h6)

## Stanza: nested pickle escapes weights_only checks

The lemmatizer in 1.14.0 performs unrestricted deserialization of compressed pickle inside a model. The advisory reports code execution as the loading user from an attacker-supplied lemma .pt. torch.load with weights_only=True does not inspect that inner pickle.

Upgrade to 1.15.0 and reject models of unknown origin. Investigate execution history and credential exposure in environments that already loaded them.

[GHSA-gh9r-c94j-cmp5](https://github.com/advisories/GHSA-gh9r-c94j-cmp5)

## Elo: constructor access in JavaScript output

An attacker-controlled Elo string can reach host code execution when generated JavaScript is executed through unfiltered constructor access. This differs from the separate advisory about directly supplied AST objects.

Upgrade @enspirit/elo to 1.0.1. Do not execute code generated from untrusted input in a process with secrets or host privileges.

[GHSA-33r5-xmm8-v6x5](https://github.com/advisories/GHSA-33r5-xmm8-v6x5)

## Elo: interpolation in generated Ruby

The Ruby backend does not sufficiently escape interpolation in emitted string literals and subtype-constraint labels. Running Ruby generated from crafted Elo can evaluate attacker-controlled expressions.

Upgrade @enspirit/elo to 1.0.1 and regenerate Ruby output. Safety of output from another backend does not establish safety of the Ruby output.

[GHSA-7w38-ggh5-v542](https://github.com/advisories/GHSA-7w38-ggh5-v542)

## Elo: validation of programmatic AST input

Integrations that construct AST objects from JSON or plugins can pass unchecked fields into JavaScript, Ruby, Python or SQL output, enabling code injection. This input boundary differs from the normal string parser.

Upgrade @enspirit/elo to 1.0.1. Validate AST types and syntax and isolate generation and execution from untrusted ASTs.

## praktor: Telegram uploads cross workspace boundaries

In 0.9.0 and earlier, a Telegram document filename can write outside uploads within the persistent agent workspace. Overwritten instruction or configuration files can affect subsequent runs. This is not proof of arbitrary writes across the host.

Upgrade to 0.9.1 and restrict allowed Telegram user IDs. Review instructions, skills, hooks and upload history in existing volumes.

## Keycloak: signature verification bypass in JWT Authorization Grant

An attacker with valid client credentials can exploit algorithm confusion in the JWT Authorization Grant flow to bypass signature verification and issue tokens for federated users linked to the affected Identity Provider. This does not establish an attack without credentials against every user.

Upgrade keycloak-services to 26.6.4. Review the affected flow, Identity Provider and client credentials and investigate unauthorized token issuance.

## Netfoil: stale records from missing TTL decrement

The advisory states that versions from 0.3.0 up to but excluding 0.6.1 do not decrement TTL and continue serving stale records. Its brief description does not establish a compromise or data leak.

Upgrade to 0.6.1 and review cache and record expiry.

## Arc: logs route registered before authentication middleware

The advisory reports unauthenticated access to recent application logs because /api/v1/logs is registered before authentication middleware even with authentication enabled. Internal paths and database names may leak; retrieval of the bootstrap admin token was not confirmed.

Place the logs route behind authentication and administrator authorization or block it if unused. Verify artifacts contain the fix commit in the table and review sensitive data in stored logs.
