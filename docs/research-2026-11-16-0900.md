## 主な論点と編集方針

- **Gitea 28.4.0（20件のCVE修正）:** 公式リリースブログで公開された20件（うち18件が今回のNVD公開窓に収録、1件は28.3.0既修正のRubyGems改行注入 `CVE-2026-118389`、1件はGo 1.27.4更新）を整理。特に自動初期化（auto-init）付きリポジトリ作成が完了する前にpushを受け付け、シンボリックリンク経由でREADME書込み時にサーバ側git hookを上書きしてGiteaシステムユーザー権限で任意コマンドを実行できる問題（`CVE-2026-125423`）と、28.0.0以降のダッシュボード検索（`GET /repo/search`）がコミット状態オブジェクト内にリポジトリ所有者のパスワードハッシュ・ソルト・メールアドレスを含めて返していた問題（`CVE-2026-123006`）が含まれる。さらに保護ファイルパターンのgit引用符迂回（`CVE-2026-123638`）やリポジトリ移管後のscoped workflow登録残留（`CVE-2026-118535`）など認可・資格情報境界の修正を確認し、**`28.4.0` 以降** への更新と28.0.0〜28.3.x運用時の所有者パスワード再設定・移管リポジトリ監査を案内した。
- **Cyrus SASL SRP認証迂回（`CVE-2026-129483`）とOkHttp証明書ピン迂回（`CVE-2026-129482`）:** Cyrus SASL `<= 2.1.28` の `srp_server_mech_step2`（`plugins/srp.c`）はクライアント公開値 `A` が `A % N == 0` であるかを検査しておらず、未認証クライアントが `A = N` を送信すると共有秘密がゼロに固定されて任意の既存ユーザーとして認証・セッション鍵確立が成立する（CVSS 4.0 9.3）。上流は2022年以降新規リリースがなく、コミット `fb3724f4` でSRPプラグイン自体を削除している。またOkHttp `<= 5.5.1` の `CertificatePinner`（`Pin.matchesHostname`）は末尾ドット付きFQDN（`example.com.`）を正規化しておらず、末尾ドット付きホスト名で接続した際にピン検査がスキップされる（コミット `30aa5897` で修正、取得時点のNVDに修正リリース版番号の記載なし）。
- **vLLM・dufs・Kroki:** vLLM `0.30.0`／`0.31.0` の `single_type_kv_cache_manager.py`（Common Prefix Handler）競合状態（`CVE-2026-129356`、`0.32.0` およびコミット `e687a251` で修正）、dufs `<= 0.46.0` のWebDAV `COPY` ハンドラが削除権限（delete permission）を検査せず既存ファイルを上書きできた認可不備（`CVE-2026-129355`、`0.47.0` およびコミット `fba13dff` で修正）、およびKroki `< 0.36.0` に追加登録されたBlockDiag系ノード `icon`・`background` 属性経由のSSRF／ローカル画像読出し（`CVE-2026-129485`、`GHSA-jwh8-j584-79hp`）と `GET /goat/svg` の反射型XSS（`CVE-2026-129484`、`GHSA-xp94-px2v-f7f2`、ともに `0.36.0` で修正）を収録した。
- **Assimp・GPAC・littlefs・MicroQuickJS・Escargot:** Assimp `<= 6.0.6` の4件（glTF `buffers[].uri` 経路遡り `CVE-2026-129477` PR `#7027`、`ParseDataURI` の `signed char` オフセット保持による127バイト超ヒープ範囲外読出し `CVE-2026-129478` PR `#7029`、`OgreBinarySerializer::ReadSubMesh` 32bit整数オーバーフロー `CVE-2026-129479` PR `#7026`、`MD2Importer::InternReadFile` ヒープ範囲外読出し `CVE-2026-129480` PR `#7028`、いずれもNVDに修正リリース版番号未記載）、GPAC `< 26.02.0` のMPEG-2 TS・XMT・DASH処理4件（`CVE-2025-71466`〜`CVE-2025-71469`、`26.02.0` およびコミット `62714f27` で修正）、`LFS_MIGRATE` 有効時のlittlefs `<= 2.11.3` の `lfs_dir_traverse()` 型混同（`CVE-2026-129490`、修正版未記載）、MicroQuickJSの `JS_Call()` 古いフレームポインタ走査（`CVE-2025-71470`、コミット `99eed3f9`）、Samsung Escargot `5.0.2` の解放後使用（`CVE-2026-124684`、コミット `8bc35b7b`）をパッチ形態別に区分した。
- **PrestaShop・FRRouting・FreedomBoxの改訂補完:** NVD改訂窓で技術条件と修正版が具体化された3件として、PrestaShop `< 8.2.9`／`< 9.2.1` のマルチショップWebservice API越境（`CVE-2026-71519`・`CVE-2026-71531`、`8.2.9`／`9.2.1` で修正）、FRRouting `bgpd` のTunnel Encapsulation属性解放後使用（`CVE-2026-129456`）における `soft-reconfiguration inbound` ピアおよび `attr_intern_reuse` 自己比較の発生条件・追加コミット `5c241056`、FreedomBox `< 26.15` の `authorized_keys` パス検査不備（`CVE-2026-123962`、`26.15` で修正）を補完した。
