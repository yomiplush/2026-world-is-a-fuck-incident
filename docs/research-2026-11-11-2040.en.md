## OpenSSH: musl, non-PAM, password settings and daemon restart

CVE-2026-123158 concerns Linux with musl and non-PAM authentication. Alpine conditions include PasswordAuthentication yes, a target account with a * password field, and another account with a $5$/$6$ hash. PAM-enabled or password-disabled configurations differ. KEV added the issue on 11/09.

Install the branch-specific Alpine fixed package and restart sshd; a package upgrade alone leaves the running daemon unchanged. If unable to upgrade, verify key access in another session before disabling password authentication, and investigate Accepted password logs, doas use and added keys.

## FortiManager: FGFM reachability, branch fixes and scoring discrepancy

CVE-2026-126261 permits unauthenticated code or command execution when the FGFM port is reachable. Fortinet lists 8.0.0→8.0.1, 7.6.0–7.6.7→7.6.8, 7.4.0–7.4.5→7.4.6 and 7.2.0–7.2.8→7.2.9. PSIRT gives CVSS 9.0 while the NVD CNA metric gives 9.8. PSIRT states Known Exploited No.

Upgrade the relevant branch, restrict FGFM reachability and audit registration and management actions. A critical advisory is not itself confirmation of exploitation or victims.

## Outlook: opening a file is required; Preview Pane excluded

CVE-2026-124194 can bypass the external-connection warning when a user opens a crafted message file, potentially exposing an NTLMv2 hash. The MSRC FAQ requires network connectivity and user interaction and excludes the Preview Pane. MSRC marks Exploited Yes; KEV added it on 11/10.

Use the MSRC product/channel table to deploy the relevant November Office fixed build. Do not describe receipt or preview alone as sufficient; investigate outbound authentication and account activity after suspicious files were opened.

## WP Duplicate: exploitation reported, no known fix

CVE-2026-123751 is an unauthenticated file-upload issue in WP Duplicate (slug local-sync) through 1.1.11. WPScan reports exploitation in the wild and No known fix. Initial publication on 11/06, NVD registration on 11/09 and the 11/10 text update are distinct.

Disable/remove the plugin or otherwise close the upload route until a fix is established. Inspect added webroot files, administrators and execution history; a version increase alone does not prove remediation.
