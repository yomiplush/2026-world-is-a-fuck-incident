別利用者のaccess token取得と固定資格情報による管理権限取得を扱う。CVE-2026-16720とCVE-2026-17403は10.0.8.0〜10.0.8.12、12.1.0.0〜12.1.1.2が対象。CVE-2026-17360は12.1.0.0〜12.1.1.2。IBMの初回公表日は11月5日で、今回の11月7日のNVD登録を攻撃開始日とはしない。

## Keycloak：client管理権限からJavaScript policy実行

authorization servicesを有効にしたclientの作成・import時のsession状態が、inline JavaScript policyのupload制限を回避させる。認証済みで委任されたclient管理権限が必要。Red HatはCVSS 9.1とImportantを併記し、対象packageをAffectedと記載するが修正版は示さない。public_dateは2026-01-07で、今回のNVD登録日と一致しない。

manage-clients相当の委任権限、client importとpolicy変更履歴を確認する。Red Hatの製品別更新情報で修正提供を追跡し、修正版を推測しない。defaultのscript制限だけで当該経路を防げるとは判断しない。

## Fiber Admin：error page設定と競合が必要なRCE

4.0.1未満で、custom database error pageが有効な場合に、管理者の設定保存と競合してrequest headerがPHP fileへ書かれる。未認証で到達できるが、error pageと競合の条件を省略しない。WPScanは4.0.1を修正版、11月5日を初回公表日とする。

4.0.1以降の修正へ更新し、custom database error page設定と生成PHP fileの改変を確認する。機能の無効化を正式な更新完了と同一視せず、設定保存時刻とアクセスログも調査する。

[WPScan / CNA](https://wpscan.com/vulnerability/42b9773d-9c69-4435-be20-ae86f52b4608/)

## LatePoint：password reset tokenとSQL条件の混同

NVDのCNA本文は5.7.6以前の予約pluginで、password resetの値がSQL条件として扱われる問題を記載する。顧客accountの乗っ取りと予約・個人情報へのアクセス、設定次第で連携WordPress accountへの影響がある。5.7.5のscalar検査だけでは解決しない。WordfenceのページはHTTP成功でも空本文で、修正版の本文確認はできなかった。

LatePointの公式更新とCNAの修正案内を確認し、実際に稼働する修正を検証する。今回確認した本文から最低修正版を断定しない。password reset、顧客account変更、予約情報へのアクセスを調査する。

## WooCommerce Registration Form：checkout側のrole認可

NVDのCNA本文は1.1.4以前でcheckout登録時のrole allowlistが欠け、未認証利用者が管理者へ昇格できると記載する。My Account側の検査はcheckout側の安全を保証しない。1.1.5へのchangeset参照はあるが、Wordfenceの空本文だけから提供版を確認済みとはしない。

checkoutでaccount作成を許す設定とpluginの更新案内を確認し、修正を含む稼働版を検証する。管理者accountの作成・role変更履歴を調査し、不要な高権限accountとsessionを失効する。
