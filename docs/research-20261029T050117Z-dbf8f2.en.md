## From PHP to the kernel and identity systems: observed artifacts and uncertainty

## Struts REST: any-setter requires configuration as well as an update

In Struts 2 versions 7.2.1–7.3.0, @StrutsParameter restrictions do not cover REST @JsonAnySetter members. JVN advises updating to 7.4.0 or later and using struts.rest.anySetter.requireAnnotations=true with @StrutsParameter(allowDynamicKeys = true). Conditions include REST use and any-setter declarations; this does not establish compromise of all Struts applications.

Action: Check the update, configuration and annotations together. Work around the issue by avoiding any-setter or validating values in the application before storage.

[JVN Struts](https://jvn.jp/jp/JVN82782759/)
