## まず優先すること

1. **実悪用が確認された公開機器・サービス**：Arista VCO、Nextcloud Built-in CODE、SiteGuard、Plexなど。更新と侵害調査を並行します。KEVの掲載順やCVSSだけで優先順位を決めません。
2. **Fortinetの緊急更新をCVE公開待ちにしない**：製品・系列別の更新先を照合します。管理画面の外部公開を制限し、設定をバックアップして対応します。
3. **Java/Pythonとアプリ同梱の証明書ストア**：ブラウザー更新で対応完了にせず、eMudhra対策が実際の通信経路に入っているか確認します。
4. **LiteLLM / ConnectWise / Railway等の資格情報**：パッチやベンダー側復旧後も、流出した鍵と追加されたクラウド権限は残り得ます。隔離・証拠保全・失効・再構築まで追います。
5. **DNS、圧縮ライブラリ、プロキシ、画像、Wasm、OTクライアント**：利用する機能・設定・同梱コピーまで棚卸しします。

これは本調査に基づく対応の優先案です。各環境の外部到達性・権限・データ重要度・復旧可能性も加味してください。
