LiteLLM and Railway: code installed, keys entrusted.

The malicious LiteLLM 1.107.0 distribution and unauthorized access to environment variables stored in Railway are separate incidents. Since API keys are affected, replacing packages or restoring services alone is insufficient.

What to check Isolate affected environments and preserve evidence. In affected LiteLLM environments, do not first launch Python or pip to investigate; revoke keys and rebuild from a clean environment.
