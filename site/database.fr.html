2 paquets npm : minage lors de l’installation

Les avis malware de GitHub décrivent un programme de minage et des mécanismes de persistance exécutés par postinstall dans dsh-plugin-blender-3d 0.2.1 et @walknpm/todo-cli 2.0.1.
