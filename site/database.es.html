Paquetes npm 2: minería durante la instalación

Los avisos de malware de GitHub describen programas de minería y mecanismos de persistencia ejecutados mediante postinstall en dsh-plugin-blender-3d 0.2.1 y @walknpm/todo-cli 2.0.1. El comportamiento varía según se disponga de root o de sudo sin contraseña. Esto no significa que todos los paquetes npm ni Blender hayan sido comprometidos.

Qué comprobar: Revise el historial de instalación de las versiones afectadas. Si ya se ejecutaron, aísle el entorno, investigue la persistencia, las comunicaciones externas y el acceso a credenciales, y revoque las claves necesarias desde un entorno seguro.
