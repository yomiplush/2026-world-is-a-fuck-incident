ABOUT / EDITORIAL POLICY

Este sitio web y cómo interpretar la información.

Infosec Briefing es un sitio de investigación independiente que recopila información sobre incidentes, vulnerabilidades y contramedidas a partir de fuentes primarias disponibles públicamente.

Operación y consultas

Documentos a revisar

Cotejamos las recomendaciones de los proveedores, los comunicados oficiales, el código fuente disponible públicamente, JVN, JPCERT/CC, IPA, NVD y la base de datos de asesoramiento de GitHub. Los informes de noticias secundarios se consideran pistas, y las condiciones y contramedidas importantes se confirman consultando las fuentes primarias.

La IA se utiliza para la recopilación y organización de datos. Se registran las fuentes, las condiciones objetivo y los puntos poco claros, y se realizan las correcciones necesarias. Dado que el impacto puede variar según el entorno de uso del producto, consulte la guía oficial y la versión funcional para obtener información definitiva.

Significado del tiempo y del número

La «hora de referencia» de cada informe marca el final del periodo de investigación. No corresponde a la hora de publicación de la página ni a la hora en que ocurrió el incidente. La adquisición de datos puede producirse después de la hora de referencia, y el texto correspondiente a ese momento se guardará.

Distinguimos entre ocurrencia, detección, publicación, registro en base de datos, revisión y adquisición. Los documentos del mismo día cuya hora de publicación no se puede confirmar se separan y se tratan como información de referencia. El número de vulnerabilidades, el número de recomendaciones y el número de incidencias no son directamente equivalentes al número de incidentes.

Confirmación de corrección y recuperación

Modificar el código fuente, proporcionar la versión corregida, implementarla en el entorno del usuario, investigar la brecha de seguridad y restablecer el servicio son etapas independientes. En lugar de marcar una acción planificada como completada, si se desconoce la versión mínima corregida, se indicará como "desconocida".

Correcciones y original

Conservaremos registros de cada período de la investigación, lo que le permitirá acceder al registro anterior desde un nuevo informe. Publicaremos la URL, la fecha y hora de adquisición, el SHA-__ 256 del texto guardado y las adquisiciones fallidas para que puedan verificarse posteriormente. Los documentos originales adquiridos están sujetos a los derechos de sus respectivos titulares y no se reinterpretarán bajo las licencias de este sitio.
