Git LFS: update developer workstations and CI

Git LFS advisories describe command execution or exposure of sensitive headers while processing untrusted inputs. Inventory Git LFS separately from Git itself.

What to check

Upgrade Git LFS 3.x to 3.8.1 or later. Verify the binaries bundled in CI images and developer workstations. The reviewed advisories list no fixed 2.x release.

A first fixed version is listed only when the advisory provides one. Advisory counts are not incident counts.
