AWS Advanced JDBC Wrapper: Java deserialization RCE via cache poisoning.

In open source driver AWS Advanced JDBC Wrapper, which provides failover and cluster connection caching for Amazon Aurora and AWS RDS, a vulnerability allowing arbitrary Java deserialization via cache poisoning (CVE-2026-14265 / GHSA-c5q4-97jw-jggh) was published. In versions 3.3.0 through 4.0.0, unsafe deserialization occurred during connection configuration cache handling, leading to potential RCE via crafted cache entries. Fixed in version 4.0.1.

What to check

Upgrade software.amazon.jdbc:aws-advanced-jdbc-wrapper to 4.0.1 or later. Validate the safety of cache sharing configurations and JDBC connection string parameters.

A first fixed version is listed only when the advisory provides one. Advisory counts are not incident counts.
