SvelteKit 3.1.1: Fixes for 4 issues including server secret leakage into client bundle via src/params.js and protocol-relative imports.

SvelteKit 3.1.1 addresses 4 vulnerabilities: build-time server-only module import guard failure when imported via src/params.js, statically replacing server secrets ($env/static/private) into the client bundle (CVE-2026-128118), protocol-relative module imports during server route resolution enabling cross-origin script execution (CVE-2026-128116), private query.batch function parameter collisions (CVE-2026-128119), and DoS while parsing remote function form data (CVE-2026-128120).

What to check

Upgrade @sveltejs/kit to 3.1.1 or later and rebuild client bundles. Applications referencing server-only modules or environment variables from src/params.js should audit deployed client assets for leaked API tokens or secrets and rotate them if necessary.

A first fixed version is listed only when the advisory provides one. Advisory counts are not incident counts.
