Active Storage: attachment alone can reach arbitrary file operations

Applications accepting untrusted uploads with mini_magick processing and a policy that permits the relevant ImageMagick coders may allow arbitrary file writes merely by attaching an image. Disk service additionally exposes files readable by the process. Preview generation and an explicit analyze call are not prerequisites.

What to check

Update activestorage to 8.0.5.2 / 8.1.4.1, check mini_magick >= 5.1 and the effective policy. Check that overrides such as MiniMagick.cli_env do not bypass it. For potentially exposed Disk service secrets, rotate/revoke secret_key_base, the master key and external tokens; do not retain exposed secrets as fallbacks.

A first fixed version is listed only when the advisory provides one. Advisory counts are not incident counts.
