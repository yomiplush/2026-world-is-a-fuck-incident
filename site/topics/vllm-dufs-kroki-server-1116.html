PRIMARY-SOURCE REVIEW · 2026-11-16T09:00:00+09:00

vLLM・dufs・Kroki：KVキャッシュ共通プレフィックス競合、WebDAV COPY上書き認可不備、BlockDiag SSRFとGoat SVG XSS

推論基盤vLLM 0.30.0・0.31.0の `single_type_kv_cache_manager.py`（Common Prefix Handler）における競合状態（CVE-2026-129356、0.32.0およびコミット `e687a251` で修正）と、ファイルサーバdufs 0.46.0以下のWebDAV `COPY` ハンドラ（`src/server.rs`）が削除権限（delete permission）を検査せずに既存ファイルを上書きできていた認可不備（CVE-2026-129355、0.47.0およびコミット `fba13dff` で修正）が公開された。またKroki 0.36.0未満について、前回収録したPlantUML・Graphviz等の4件に加え、新たにBlockDiag系エンジンのノード `icon`・`background` 属性を通じた未認証SSRFおよびサーバ内画像ファイル読出し（CVE-2026-129485、GHSA-jwh8-j584-79hp）と、`GET /goat/svg` の `svg-color-dark-scheme`／`svg-color-light-scheme` オプション未検証による反射型XSS（CVE-2026-129484、GHSA-xp94-px2v-f7f2）の2件が登録され、いずれも0.36.0で修正されている。

確認すること

vLLMを0.32.0以降へ、dufsを0.47.0以降へ、Krokiを0.36.0以降へ更新する。WebDAVを公開または共有しているdufs環境では削除権限を持たないアカウントによる既存ファイル上書きの有無を確認する。

修正版は勧告の記載がある場合だけ示します。勧告数は被害件数ではありません。
