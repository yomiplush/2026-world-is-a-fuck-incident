PRIMARY-SOURCE REVIEW · 2026-11-17T09:00:00+09:00

MCP server boundaries: Cluster takeover via pod_regex argument injection in Kubeshark 53.4.0 and code-review-mcp-server 1.5.3.

Critical vulnerabilities were confirmed in Model Context Protocol (MCP) implementations for AI agents: Kubeshark 53.1.0 through 53.3.9 passes pod_regex positional arguments to tap without -- separators, allowing --set Helm argument injection to redirect privileged DaemonSet images to attacker registries for node and cluster takeover (CVE-2026-129236), alongside unvalidated destination file writes in download_file (CVE-2026-129235). In code-review-mcp-server prior to 1.5.3, unsanitized folderPath and baseBranch parameters enable shell command injection (CVE-2026-68934) and host RCE.

What to check

Upgrade Kubeshark to 53.4.0 or later and code-review-mcp-server to 1.5.3 or later. Enforce least privilege for tools accessible to LLM agents and audit input sanitization against shell metacharacters and --set argument injection.

A first fixed version is listed only when the advisory provides one. Advisory counts are not incident counts.
