Air Terminal 6: OS command injection requires management login

JVN published this on 11/12. On v1.01.80 and earlier, a user able to log in to the web administration interface can execute commands as root. This is not an unauthenticated Internet-wide condition. The developer says fixed firmware has been deployed and disconnected devices update automatically on reconnection, so no user action is required.

What to check

Check the official automatic-update conditions and device connectivity. Do not invent a fixed firmware number, which JVN does not list. Limit unnecessary management-interface access and shared credentials.

A first fixed version is listed only when the advisory provides one. Advisory counts are not incident counts.
