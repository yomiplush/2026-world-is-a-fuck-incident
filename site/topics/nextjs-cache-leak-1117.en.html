Next.js 16.4.5: Information disclosure across root params in unstable_cache calling 'use cache' on cold fill race.

In Next.js 16.3.0 through 16.4.4, using the same 'use cache' function directly and through unstable_cache() causes cross-request deduplication race on cold process start when reading root params. Before mismatch rejection, the in-flight fill is shared and persisted under a cache key omitting root params, serving cached data to requests with different root params (CVE-2026-119790).

What to check

Upgrade Next.js to 16.4.5 or later. Prior to 16.4.5, avoid calling 'use cache' inside unstable_cache(), and inspect application caches for cross-tenant data leaks.
