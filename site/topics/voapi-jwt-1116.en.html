VoAPI: SQL injection in filter keys can expose a JWT signing key

CVE-2026-129540 starts with an authenticated user on VoAPI 1.0.0–1.2.0. The CNA record describes search[...] keys being interpreted as SQL column names on routes such as GET /api/log, exposing the HS256 signing key in the option table and allowing forged manager JWTs. Direct unauthenticated exploitation and a fixed release number were not established.

What to check

Restrict access to user-facing search APIs and verify an allowlist of column names. Where exposure is suspected, replace the signing key, invalidate existing tokens and investigate management API and external service credential use.
