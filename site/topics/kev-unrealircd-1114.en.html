UnrealIRCd: added to KEV, label-tag newline injection executes commands with server authority

CISA added CVE-2026-114713 to KEV on 11/13 (due 11/16). On a network with 2 or more linked servers, injecting newlines into the IRCv3 labeled-response (label) tag inserts arbitrary commands into server-to-server traffic, allowing an ordinary user to run KILL, GLINE and other actions with server or IRCOp authority. Release 6.2.7.1 and hot-patch bundle-20261107 fix this critical flaw and decloak or DoS issues (9 fixes in total).

What to check

On 6.0.0–6.2.7, apply `./unrealircd hot-patch bundle-20261107` and verify `5.0-hot-patch-bundle-20261107` via `./unrealircd module-status|grep labeled-response`, or upgrade to 6.2.7.1 and restart. The temporary SPAMFILTER on 6.0.4+ does not fix the other 8 issues. End-of-life 5.x requires adding `blacklist-module "labeled-response";` and a full restart (not rehash), though EOL versions remain unsafe.

A first fixed version is listed only when the advisory provides one. Advisory counts are not incident counts.
