AWS Advanced JDBC Wrapper：キャッシュ汚染経由のJava直列化復元RCE

Amazon AuroraやAWS RDS向けにフェイルオーバーやクラスタ接続キャッシュを提供するオープンソースドライバAWS Advanced JDBC Wrapperにおいて、キャッシュ汚染経由で任意のJava直列化復元が実行される脆弱性（CVE-2026-14265 / GHSA-c5q4-97jw-jggh）が公表された。バージョン3.3.0から4.0.0において、接続構成キャッシュの処理で不安全なデシリアライズが行われ、細工されたキャッシュエントリによりRCEに至る可能性がある。バージョン4.0.1にて修正された。

確認すること

software.amazon.jdbc:aws-advanced-jdbc-wrapperを4.0.1以降へ更新する。キャッシュ共有設定およびJDBC接続文字列パラメータの安全性を検証する。

修正版は勧告の記載がある場合だけ示します。勧告数は被害件数ではありません。
