Silverstripe Framework 6.2.13: Fixes for 6 issues including i18n task writer RCE, ClassName tampering, and privilege escalation.

In Silverstripe Framework 6.0.0 through 6.2.12, the writer parameter in i18nTextCollectorTask is passed unvalidated to the injector, allowing arbitrary object instantiation and RCE (CVE-2026-91115). In dev mode the path is accessible without authentication. The release also resolves unauthorized record type change via ClassName (CVE-2026-91113), SecurityAdmin privilege escalation (CVE-2026-91112), GridFieldDetailForm auth bypass (CVE-2026-88989), and SVG/XHTML data URI XSS (CVE-2026-88988, CVE-2026-88987). Silverstripe CMS 5 is unaffected by CVE-2026-91115.

What to check

Upgrade Silverstripe Framework to 6.2.13 or later. Verify that dev mode is disabled in production environments and enforce input validation for class names and administrative access.

A first fixed version is listed only when the advisory provides one. Advisory counts are not incident counts.
