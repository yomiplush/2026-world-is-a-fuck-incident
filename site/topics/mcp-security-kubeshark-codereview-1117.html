MCPサーバーの境界：Kubeshark 53.4.0のpod_regex引数注入によるクラスタ奪取とcode-review-mcp-server 1.5.3

AIエージェント向けModel Context Protocol（MCP）実装において複数の重大な脆弱性が確認された。Kubeshark 53.1.0〜53.3.9では、start_kubesharkツールのpod_regex引数が--区切りなしで渡されるため、--setでHelmオプションを注入して特権DaemonSetコンテナイメージを攻撃者レジストリへリダイレクトし、ノードおよびクラスタ管理者権限を奪取可能（CVE-2026-129236）。またdownload_fileツールによる任意パス書込み（CVE-2026-129235）も判明。code-review-mcp-server 1.5.3未満ではfolderPath/baseBranchのシェルコマンド注入（CVE-2026-68934）によりホストOS上で任意コード実行が可能。

確認すること

Kubesharkを53.4.0以降へ、code-review-mcp-serverを1.5.3以降へ更新する。LLMエージェントから呼び出されるMCPツールには最小権限を適用し、引数のシェルメタ文字やオプション注入（--set等）に対する厳格な入力バリデーションを確認する。

修正版は勧告の記載がある場合だけ示します。勧告数は被害件数ではありません。
