WordPressプラグイン：Custom Block Builder・Give Peer-to-Peer・Auth Armor・Valitor等の未認証RCE・認証迂回・SQLi

公開窓でWordPressプラグインの脆弱性56件が登録された。特にCustom Block Builder 3.0.0未満のRESTルート権限検査が非エラー応答を返して許可扱いとなり未認証で任意PHPコードを実行できる問題（CVE-2026-127048、3.0.0で修正）、Give - Peer-to-Peerの未認証SQLインジェクション（CVE-2026-82568、2.9.3以下）と認可迂回・メディア添付（CVE-2026-82663、2.9.5以下、両者の組合せで未認証RCE）、Auth Armor 1.0.3以下の未認証ハンドラによるAPI資格情報漏えいと管理者登録リセット・乗っ取り（CVE-2026-110960、修正版未記載）、Valitor for WooCommerce 1.9.41未満のハードコード既定シークレットによる決済完了コールバック偽造（CVE-2026-103361、1.9.41で修正）が含まれる。さらにAdvanced Form Integration 2.11.3以下（CVE-2026-125769）とMCP Server for WordPress 2.0.3以下（CVE-2026-125771）の権限昇格、Estatik 4.3.6以下（CVE-2026-125795）とGrandPrix Core 1.0以下（CVE-2026-129091）のPHPローカルファイルインクルード、Document Library Pro 4.2.2未満（CVE-2026-122662）とTestimonial Slider 3.0.2以下（CVE-2026-125449）のPHPオブジェクトインジェクション、WP Data Access 5.5.92以下（CVE-2026-125832）とRegistrationMagic 6.1.0.4未満（CVE-2026-110984・CVE-2026-110987・CVE-2026-110989）のSQLi／プロフィール改ざん、Membership Plugin 4.0.6未満の未認証文字コード変換による4バイト文字破損とStripe client secret露出（CVE-2026-114451・CVE-2026-114452）が公表された（Patchstack由来の「through X」表記は取得時点のNVDに修正版番号の明記がないため推測で補わない）。

確認すること

修正版が明記されているプラグイン（Custom Block Builder 3.0.0、Valitor for WooCommerce 1.9.41、RegistrationMagic 6.1.0.4、Membership Plugin 4.0.6、Document Library Pro 4.2.2、WPGraphQL 2.27.1、Burst Statistics 3.7.5等）は該当版以降へ更新し、NVD上で上限版のみ記載または修正未確認のプラグイン（Auth Armor 1.0.3以下、Give - Peer-to-Peer 2.9.5以下、Advanced Form Integration 2.11.3以下、Estatik 4.3.6以下等）はベンダー配布元の最新修正版確認または一時無効化を行う。

修正版は勧告の記載がある場合だけ示します。勧告数は被害件数ではありません。
