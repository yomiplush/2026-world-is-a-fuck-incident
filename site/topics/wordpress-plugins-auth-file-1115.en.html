WordPress plugins and themes: Authentication bypass and file manipulation in Shipo, AutomatorWP Pro, MemberDash, Cloud Storage Manager and Optimole

Multiple WordPress plugin and theme vulnerabilities were published in NVD, including: Shipo 1.6 through 1.8.0 parsing `LOGGED_IN_COOKIE` without verifying its cryptographic signature and allowing query-string REST route bypass for unauthenticated administrator impersonation (CVE-2026-19907); Swipe through 1.4 issuing administrator session cookies without proper authentication (CVE-2026-119258); AutomatorWP Pro webhook addon through 1.4.4 allowing unauthenticated arbitrary password resets when an automation leaves the Update-User ID blank (CVE-2026-126173); MemberDash through 1.8.7 allowing subscriber-level mass-assignment in `user_account_manager()` to overwrite administrator email and password (CVE-2026-18053); Cloud Storage Manager for Fluent Forms through 1.2.0 allowing unauthenticated Google Drive connection saving and filename path traversal for arbitrary file writes (CVE-2026-120522); Optimole through 4.2.19 allowing arbitrary file deletion triggered when an administrator renames an attachment (CVE-2026-124969, fixed in 4.2.20); SEOJuice before 2.12.0 disabling site-wide REST nonce protection (CVE-2026-123046); and Quick Page/Post Redirect Plugin before 5.2.4 containing a hidden update mechanism (CVE-2026-126697).

What to check

Update affected plugins to patched releases where available (Optimole 4.2.20, SEOJuice 2.12.0, Quick Page/Post Redirect Plugin 5.2.4, Shipo with changeset 3701532, Cloud Storage Manager with changeset 3656663) or deactivate/remove them, and audit administrator accounts and REST API changes (where NVD does not list a fixed version number, do not guess one; check vendor advisories).

A first fixed version is listed only when the advisory provides one. Advisory counts are not incident counts.
