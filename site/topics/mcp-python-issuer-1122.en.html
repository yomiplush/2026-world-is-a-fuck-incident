MCP Python SDK: configure the expected OAuth issuer

An OAuth client could send credentials to an unexpected authorization server. Some configurations can still omit the issuer in fixed releases, so audit the dependency and its configuration.

What to check

Upgrade mcp to 1.30.0 or 2.2.0 or later for your branch and configure the trusted issuer on a supported provider. If misdelivery is suspected, review logs and revoke and rotate affected credentials.
