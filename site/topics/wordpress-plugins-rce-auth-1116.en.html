WordPress plugins: Unauthenticated RCE, authentication bypass, and SQLi across Custom Block Builder, Give Peer-to-Peer, Auth Armor, Valitor, and others

In the publication window, 56 WordPress plugin vulnerabilities were recorded. Highlights include unauthenticated arbitrary PHP execution in Custom Block Builder prior to 3.0.0 where a REST route permission check returned a non-error response treated as authorized (CVE-2026-127048, fixed in 3.0.0); unauthenticated SQL injection (CVE-2026-82568, 2.9.3 and earlier) and authorization bypass / media attachment (CVE-2026-82663, 2.9.5 and earlier, chaining to unauthenticated RCE) in Give - Peer-to-Peer; unauthenticated handler API credential disclosure and admin registration reset/takeover in Auth Armor 1.0.3 and earlier (CVE-2026-110960, fixed version not listed); and payment completion callback forgery via a hardcoded default secret in Valitor for WooCommerce prior to 1.9.41 (CVE-2026-103361, fixed in 1.9.41). Additional disclosures include privilege escalation in Advanced Form Integration 2.11.3 and earlier (CVE-2026-125769) and MCP Server for WordPress 2.0.3 and earlier (CVE-2026-125771), PHP local file inclusion in Estatik 4.3.6 and earlier (CVE-2026-125795) and GrandPrix Core 1.0 and earlier (CVE-2026-129091), PHP object injection in Document Library Pro prior to 4.2.2 (CVE-2026-122662) and Testimonial Slider 3.0.2 and earlier (CVE-2026-125449), SQLi and profile tampering in WP Data Access 5.5.92 and earlier (CVE-2026-125832) and RegistrationMagic prior to 6.1.0.4 (CVE-2026-110984, CVE-2026-110987, CVE-2026-110989), and unauthenticated charset conversion 4-byte character corruption and Stripe client secret exposure in Membership Plugin prior to 4.0.6 (CVE-2026-114451, CVE-2026-114452) (for Patchstack 'through X' entries lacking a fixed version in NVD at capture time, we do not guess fixed version numbers).

What to check

Update plugins with documented fixed versions (Custom Block Builder 3.0.0, Valitor for WooCommerce 1.9.41, RegistrationMagic 6.1.0.4, Membership Plugin 4.0.6, Document Library Pro 4.2.2, WPGraphQL 2.27.1, Burst Statistics 3.7.5, etc.) to those versions or later; for plugins where NVD lists only an upper affected bound or no confirmed fix (Auth Armor 1.0.3 and earlier, Give - Peer-to-Peer 2.9.5 and earlier, Advanced Form Integration 2.11.3 and earlier, Estatik 4.3.6 and earlier, etc.), verify vendor releases or temporarily deactivate the plugin.

A first fixed version is listed only when the advisory provides one. Advisory counts are not incident counts.
