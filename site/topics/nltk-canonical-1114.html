NLTK：C拡張path検証欠落とcorpus symlink・parser CPU枯渇の5勧告

NLTK 3.10.4で修正された5件の正本勧告。`BllipParser` がmodel pathを `pathsec` 検証なしでC拡張へ渡し任意file読出しに至る問題（CVE-2026-126295）、`YCOECorpusReader` が `psd`／`pos` directoryのsymlinkを解決せずcorpus外のfileを読む問題（CVE-2026-126304）、および `SteppingRecursiveDescentParser.parse()`（CVE-2026-126303）、`TreebankWordTokenizer.span_tokenize`（CVE-2026-126300）、`LegalitySyllableTokenizer.tokenize`（GHSA-gpwc-27cw-rh9r）のCPU枯渇を収録する。

確認すること

nltkを3.10.4へ更新する。外部入力や未信頼のmodel path・corpusアーカイブ・文法・長大tokenをこれらのAPIへ直接渡している経路を点検する。

修正版は勧告の記載がある場合だけ示します。勧告数は被害件数ではありません。

勧告別：対象バージョンと修正版（5件）

GHSA-fg9w-wfp5-j933

NLTK: BllipParser passes caller-supplied model paths to the bllipparser C extension with no pathsec check, enabling arbitrary read

  • nltk (pip): 対象 >= 3.10.0, <= 3.10.3 → 修正版 3.10.4

GHSA-gpwc-27cw-rh9r

NLTK: Quadratic CPU exhaustion in LegalitySyllableTokenizer.tokenize via unguarded onset reversal loop

  • nltk (pip): 対象 >= 3.6, <= 3.10.3 → 修正版 3.10.4

GHSA-ffr9-mgrr-wcvr

NLTK: Quadratic CPU exhaustion in TreebankWordTokenizer.span_tokenize via list.pop(0) in quote-restore loop

  • nltk (pip): 対象 >= 3.2.5, <= 3.10.3 → 修正版 3.10.4

GHSA-8fx7-8jr8-84rv

NLTK: Unbounded CPU consumption in SteppingRecursiveDescentParser.parse() with ambiguous or self-embedding grammars

  • nltk (pip): 対象 <= 3.10.3 → 修正版 3.10.4

GHSA-qg35-44qx-7vrr

NLTK: Symlink escape in YCOECorpusReader lets a psd/pos directory symlink read files outside the corpus root within the data sandbox

  • nltk (pip): 対象 >= 3.10.0, <= 3.10.3 → 修正版 3.10.4
