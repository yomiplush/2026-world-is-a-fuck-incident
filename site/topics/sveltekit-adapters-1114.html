SvelteKit：adapter別のroute設定注入とNode server crashの4勧告

`reroute` が不正なpercent-encode pathを書き換えた際の未処理URIErrorによるcrash（CVE-2026-128117、`@sveltejs/kit`）、prerender時にcrawlされたlinkがVercel route設定で正規表現として解釈される問題（CVE-2026-128121、`adapter-vercel`／`adapter-static`）、Cloudflare `_redirects` への規則注入（CVE-2026-128122、`adapter-cloudflare`）、および `fetch` proxy時のimmutable request header追加によるcrash（CVE-2026-128123、`adapter-node`）の4件。

確認すること

利用しているpackageと系列に合わせ、`@sveltejs/kit` を2.70.4／3.1.1、`@sveltejs/adapter-vercel` を6.3.5／7.0.2、`@sveltejs/adapter-static` を3.0.11／4.0.1、`@sveltejs/adapter-cloudflare` を7.2.10／8.0.2、`@sveltejs/adapter-node` を5.5.8／6.0.1へ更新し、再build・再配備する。

修正版は勧告の記載がある場合だけ示します。勧告数は被害件数ではありません。
