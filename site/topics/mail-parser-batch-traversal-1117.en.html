mail-parser 4.6.3: Fixes for 6 issues including aborted attachment saves, path traversal, and sender IP spoofing.

In mail-parser 4.6.0 through 4.6.2, write_attachments() lacks per-part exception isolation for crafted MIME parts (NUL in RFC 2231 filenames or NAME_MAX overflow), silently aborting extraction of all subsequent attachments and blinding downstream scanners (CVE-2026-129301). The release also fixes attachment path traversal (CVE-2026-129296), sender IP spoofing in get_server_ipaddress() (CVE-2026-129297), polynomial ReDoS in header parsing (CVE-2026-129295), uncaught header parse exceptions (CVE-2026-129299), and OverflowError/OSError on invalid dates (CVE-2026-129300).

What to check

Upgrade mail-parser to 4.6.3 or later. In mail gateway or malware analysis pipelines using mail-parser, inspect extraction logs for past aborted attachment batches.
