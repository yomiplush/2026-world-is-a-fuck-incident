pgEdge RAG: ordinary concurrent queries can mix results across tenants

A shared BM25 index clears, populates and searches under separate locks, so ordinary concurrent unauthenticated queries can return another tenant’s documents. No injection or malformed input is needed. Separate advisories cover unbounded corpus reads and provider-key fragments in errors.

What to check

Upgrade the RAG Server product release to 2.0.0 or later. Go module first_patched_version values identify commits through pseudo-versions and differ from product releases. hybrid_enabled: false temporarily bypasses the shared index. The server’s own logs cannot retrospectively identify affected responses; rotate exposed provider credentials.

A first fixed version is listed only when the advisory provides one. Advisory counts are not incident counts.
