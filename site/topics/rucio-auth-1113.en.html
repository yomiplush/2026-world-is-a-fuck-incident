Rucio: SSH challenges accepted as authentication tokens enable administrator impersonation

SSH challenges are nonces for a later key exchange, but are stored alongside authentication tokens and not distinguished during validation. An unauthenticated caller can request a challenge for an arbitrary account and use it within its short lifetime to access APIs as that account, including an administrator. Exact affected and fixed branches are retained below.

What to check

Update rucio to a fixed release on its branch: 35.9.1 / 38.6.1 / 40.4.2 / 41.1.1 or later. Review API exposure, authentication and privileged operations. Keep nonces separate from authenticated credentials.
