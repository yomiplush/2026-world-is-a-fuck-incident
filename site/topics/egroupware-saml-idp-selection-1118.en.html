EGroupware: Authentication redirection vulnerability via user-controlled external IdP parameter in SAML authentication.

In open source groupware EGroupware, an IdP selection flaw in SAML authentication handling (CVE-2026-63672 / GHSA-pr4x-6fj4-gm4h) was fixed. In the login() function, user-supplied idp request parameter was passed directly to SimpleSAMLphp requireAuth() with only a prefix check, allowing an attacker to specify a malicious IdP entity to redirect authentication and inject forged authentication assertions. Fixed in EGroupware 23.1.20260601 and 26.6.20260616.

What to check

Upgrade EGroupware to 23.1.20260601 or later or 26.6.20260616 or later. Confirm that trusted IdP entity allowlist matching is strictly enforced.
