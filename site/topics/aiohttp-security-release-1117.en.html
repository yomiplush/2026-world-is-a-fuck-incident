AIOHTTP 3.14.4: Fixes for 9 vulnerabilities including event loop stalls, Base64 multipart bypass, and WebSocket overload.

aio-libs/aiohttp 3.14.4 addresses 9 vulnerabilities: polynomial event loop stall in Application.add_domain() wildcard Host matching (CVE-2026-128124), Base64 multipart client_max_size limit bypass (CVE-2026-128127), event loop block on excessive URL-encoded form fields (CVE-2026-128126), unbounded cookie storage in CookieJar (CVE-2026-128125), WebSocket max_msg_size integer overflow bypass (CVE-2026-128128), unbounded data buffering during HTTP upgrade requests (CVE-2026-128129), pure-Python parser request replay on declined upgrades (CVE-2026-128130), excessive CPU use from concatenated compressed streams (CVE-2026-128131), and WebSocket receive queue limit bypass (CVE-2026-128132).

What to check

Upgrade aiohttp to 3.14.4 or later. Validate servers configuring multi-wildcard masks in add_domain, or handling Base64 multipart uploads and WebSockets against DoS and memory exhaustion.
