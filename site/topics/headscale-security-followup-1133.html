headscale 0.29.7とTailscale：制御サーバーとノードを別々に更新

10月30日公開のheadscale 0.29.7はTailworm等の指摘に対するセキュリティリリースで、headscale 0.29.7とTailscale 1.104.4以降の両方を推奨する。SSH・Serveの修正は各ノードのtailscaledで動作し、制御サーバーだけの更新では適用されない。11月12日のTS-2026-018は条件付きのKubernetes API proxy問題で、別途1.104.7以降が必要。

確認すること

headscaleと各ノードの実稼働版を別々に確認する。専用ProxyGroupのkube-apiserver proxyでacceptRoutesを有効にしサブネット経由の到達を許す場合は、1.104.7以降へ更新してKubernetes監査ログのなりすましを調査する。

修正版は勧告の記載がある場合だけ示します。勧告数は被害件数ではありません。
