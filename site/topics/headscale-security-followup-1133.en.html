headscale 0.29.7 and Tailscale: update control servers and nodes separately

Released on 10/30, headscale 0.29.7 addresses Tailworm and other security findings and recommends both headscale 0.29.7 and Tailscale 1.104.4 or later. SSH and Serve fixes run in each node's tailscaled; updating only the control server does not apply them. 11/12 bulletin TS-2026-018 concerns a conditional Kubernetes API proxy issue and separately requires 1.104.7 or later.

What to check

Check the running headscale and node versions separately. For dedicated kube-apiserver ProxyGroup deployments with acceptRoutes enabled and access from routed subnets, update to 1.104.7 or later and investigate Kubernetes audit logs for unexpected impersonation.

A first fixed version is listed only when the advisory provides one. Advisory counts are not incident counts.
