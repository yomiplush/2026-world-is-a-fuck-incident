NLTK 3.10.4：dot2imgのGraphviz実行におけるPATHインジェクション・chat80のシンボリックリンク脱出など3件の修正

自然言語処理ツールキットNLTK 3.10.4にて3件の脆弱性が修正された。nltk.parse.dependencygraph.dot2imgがGraphvizのdot実行可能ファイルを探索する際、NLTKの信頼済み実行チェックポイントを迂回し裸のコマンド名で解決してraw subprocess.runを実行するため、書込み可能なPATH要素によるローカルコード実行が可能になる問題（CVE-2026-128134）、chat80.sql_queryでシンボリックリンクを用いてpathsecサンドボックスを脱出しルート外のSQLite DBを読出す問題（CVE-2026-126302）、およびsave/load_maxent_paramsにおけるパストラバーサル（CVE-2026-126296）を修正。

確認すること

nltkを3.10.4以降へ更新する。共有環境やマルチユーザー環境でGraphviz連携機能を使用している場合は、PATH環境変数の設定およびカレントディレクトリの書込み権限を確認する。

修正版は勧告の記載がある場合だけ示します。勧告数は被害件数ではありません。
