Nuxt 4.6.4: Fixes for 5 issues including %2F encoded slash route bypass, DNS rebinding, and SSR error leaks.

Nuxt 4.6.4 addresses 5 vulnerabilities: encoded slashes (%2F) in request paths bypassing routeRules on catch-all routes (CVE-2026-128071, incomplete fix for GHSA-6gq8-jgmh-3ffp), built source served to DNS rebinding pages by @nuxt/webpack-builder and @nuxt/rspack-builder dev servers (CVE-2026-128072), degree-2 quadratic cost payload URL generation on repeated slashes (CVE-2026-128074), unhandled error message and data exposure during server-side rendering (CVE-2026-128075), and colliding island props sharing one /__nuxt_island path (CVE-2026-128076).

What to check

Upgrade Nuxt to 4.6.4 or later. In catch-all routes relying on routeRules for authentication or access control, verify on staging that requests containing %2F are enforced properly. Do not expose development servers to untrusted networks.

A first fixed version is listed only when the advisory provides one. Advisory counts are not incident counts.
