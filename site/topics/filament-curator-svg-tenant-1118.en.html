Filament Curator: Stored XSS via inline SVG serving and multi-tenant picker search disclosure.

In media management plugin Filament Curator for Laravel Filament, 2 vulnerabilities have been resolved. Lack of sanitization on SVG file uploads served inline allowed stored XSS via SVGs containing malicious scripts (CVE-2026-69241). In addition, in multi-tenant environments, media picker search queries omitted tenant filtering, exposing media metadata belonging to other tenants (CVE-2026-63389). Resolved in v3.7.9, v4.1.2, v5.1.2 (XSS fix) and v3.7.8, v4.1.1, v5.1.1 (tenant leak fix) respectively.

What to check

Upgrade awcodes/filament-curator to the latest release for each major version (3.7.9 / 4.1.2 / 5.1.2 or later). Verify the security of previously uploaded SVG files.

A first fixed version is listed only when the advisory provides one. Advisory counts are not incident counts.
