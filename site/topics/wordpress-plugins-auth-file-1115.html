WordPressプラグイン・テーマ：Shipo・AutomatorWP Pro・MemberDash・Cloud Storage Manager・Optimole等の認証迂回とファイル操作

公開窓でWordPressプラグイン・テーマの脆弱性が多数登録された。特にShipo 1.6〜1.8.0の署名未検証 `LOGGED_IN_COOKIE` 解析とクエリ文字列によるREST経路制限迂回（CVE-2026-19907、未認証での管理者なりすまし）、Swipe 1.4以下の未認証管理者セッションCookie発行（CVE-2026-119258）、AutomatorWP Pro Webhookアドオン 1.4.4以下のUser ID空欄設定時における未認証の任意パスワード再設定（CVE-2026-126173）、MemberDash 1.8.7以下の `user_account_manager()` 一括代入（mass-assignment）による管理者メール・パスワード上書き（CVE-2026-18053）、Cloud Storage Manager for Fluent Forms 1.2.0以下の未認証Google Drive接続保存とファイル名経路遡りによる任意ファイル書込み（CVE-2026-120522）、Optimole 4.2.19以下の管理者リネーム操作を契機とする任意ファイル削除（CVE-2026-124969、4.2.20で修正）、SEOJuice 2.12.0未満のサイト全体REST nonce保護無効化（CVE-2026-123046）、Quick Page/Post Redirect Plugin 5.2.4未満の隠し更新機構（CVE-2026-126697）が含まれる。

確認すること

該当プラグインを使用している場合は修正済み版（Optimole 4.2.20、SEOJuice 2.12.0、Quick Page/Post Redirect Plugin 5.2.4、Changeset 3701532適用後のShipo、Changeset 3656663適用後のCloud Storage Manager等）への更新またはプラグインの停止・削除を行い、不審な管理者アカウント追加やREST API経由の設定変更を確認する（NVD本文に修正版番号が未記載の項目は推測で補わずベンダ案内を確認）。

修正版は勧告の記載がある場合だけ示します。勧告数は被害件数ではありません。
