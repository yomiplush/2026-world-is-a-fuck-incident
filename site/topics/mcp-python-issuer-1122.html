MCP Python SDK：OAuth発行者を明示

OAuthクライアントが想定外の認可サーバーへ認証情報を送る可能性があります。修正版でも、発行者を省略する構成が残るため、依存関係と設定の両方を確認してください。

確認すること

mcp 1.30.0または2.2.0以降へ更新し、対応するプロバイダーで信頼するissuerを設定してください。認証情報の誤送信が疑われる場合はログを確認し、対象の認証情報を失効・再発行してください。

修正版は勧告の記載がある場合だけ示します。勧告数は被害件数ではありません。
