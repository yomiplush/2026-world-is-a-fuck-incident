Aspire: an unauthenticated NotFound route is not fixed by a runtime update

The Aspire Dashboard NotFound route may allow unauthenticated telemetry deletion. Standalone browser-token deployments may also disclose the browser token; AppHost-hosted dashboards are affected too. Releases 13.6.3 and 13.6.4 are not fixed, and a .NET runtime/SDK update does not replace the Dashboard.

What to check

Update Dashboard to 13.6.5 or later. Replace container images and existing deployment manifests and redeploy. Check resolved Dashboard SDK packages, CLI bundles or custom paths selected by AppHost, then restart. A package-reference edit alone does not establish the running version.

A first fixed version is listed only when the advisory provides one. Advisory counts are not incident counts.
