PHPの公式修正と、公開前の試行

CloudflareはPHP修正版の公開より前に試行を観測。PHPは8.2.35 / 8.3.36 / 8.4.27 / 8.5.12を公開した。アプリの変更や一つの設定だけで全経路を修正したことにはならない。

確認すること 全ワーカーとコンテナの稼働版を確認する。EOL系列はサポート中の系列への移行を検討し、部分緩和を修正完了としない。

Node.js / GitLab / DNSも独立した更新

Node.jsの圧縮処理等、GitLabの正規表現エンジン、BINDなどのDNS処理は別の欠陥。PHPを更新してもこれらは直らない。

確認すること Node.jsは22.23.4 / 24.22.1 / 26.12.1、GitLabは対応する系列別修正版、BINDは9.20.30 / 9.21.27等を照合する。

LiteLLMとRailway：入れたコード、預けた鍵

LiteLLM 1.107.0の悪性配布物と、Railwayに保存された環境変数への不正アクセスは別の事案。被害にAPI鍵が含まれるため、パッケージ差し替えやサービス復旧だけでは終わらない。

確認すること 対象環境を隔離し証拠を保存。LiteLLM対象環境では調査のために先にPythonやpipを起動せず、クリーンな環境から鍵を失効・再構築する。
